# 文笔坐标 · 中文创意写作盲评汇总

来源：`Projects/llmtest`（107 题，10 个模块）的盲评结果。6 位裁判分别对匿名作答打分（存放在 `~/Documents/` 下的 dsv4p / gemini3.7 / gemini4 / muse1.2 / muse1.3 / opus5.5 目录），汇总时用 `手动解盲（主会话专用）/03_映射表/mapping.csv` 解盲。源目录一个文件都没改。

## 总分算法

1. 单题总分取裁判记录的「总分」：通用十维均分 × 0.5 + 专项分 × 0.5；多语言分段题（J01–J06、J09、J12–J16）用多语言合成公式。
2. **剔除自评**：裁判本身也是参赛模型时，它给自己的分不计入。
3. **去极值均分**（主榜用这个分）：对每个模型，先按裁判分别算出它的题均分，去掉最高、最低各一位裁判后再取平均。分数旁的灰色 `+a / −b` 表示最高、最低那位裁判的分与该均值之差，用来看裁判之间的分歧。
4. 全裁判均分：剔除自评后，每题先对所有裁判取均值，再对各题等权平均。只作参考列出。
5. 缺答的题不计入该模型的均分。GLM 5.3 只答了 4 题，已从汇总中移除。
