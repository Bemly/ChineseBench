# C · 人物与对白

> 考察范围：人物台词、对白、潜台词、心理描写、旁白、意识流、多视角、群像、多主角、活人感。

## T-C01｜纯对白离婚戏

> 考察：对白 · 说话人辨识 · 潜台词 · 无旁白叙事 ｜ 难度：★★★★ ｜ 模式：单轮

```user
只用对白，写一场 1200 字左右的戏：一对结婚十一年的夫妻，在协议离婚的前一晚，坐在客厅里分家里的东西。

硬性要求：
- 全文只有引号内的台词，不允许任何叙述、动作描写、提示语（包括"他说""她笑了"）；
- 读者必须能始终分清是谁在说话；
- 他们之间有一件从未说开的事，整场对话都没有直接说出来，但读者读完能猜到是什么；
- 结尾要有一个转折。
```

```check
{"target_chars": 1200}
```

**评分要点**
- 出现任何引号外叙述即重扣。
- 说话人辨识靠什么：称呼、口头禅、关注点、句子长短——而不是靠"老公你说"这类生硬点名。
- 那件"没说开的事"读者能否猜到（请裁判写出它的猜测）。
- 分东西的过程是否有具体物件（一台旧相机、孩子的出生证明、两人一起养死的那盆绿萝）。

## T-C02｜六个人回答同一个问题

> 考察：人物台词 · 声音辨识度 · 方言与职业语 ｜ 难度：★★★ ｜ 模式：单轮

```user
下面是 6 个人物：
1. 一位 82 岁、参加过对越自卫反击战的退休老兵，湖南人；
2. 一个 22 岁的游戏主播，正在直播中；
3. 一位上海弄堂里 60 岁的退休会计阿姨；
4. 一位研究宗教人类学的大学教授；
5. 一个 14 岁、说话有点口吃的男孩；
6. 一个在北京开了二十年出租车的师傅。

请让他们每人用 150～250 字回答同一个问题："你觉得人死了以后会去哪儿？"

输出时打乱顺序，只用 ①～⑥ 标注，不写人物身份；在最后单独给出"答案对照表"。要求读者在不看对照表的情况下，也能把六段话和六个人对上。
```

**评分要点**
- 盲测：把六段话交给另一个人（或另一个模型）配对，正确率即为主分。
- 方言是否到位且不过量（上海话"阿拉""伊""老早"适度；北京话儿化、"您瞧"；湖南老兵可有"咯""哒"）。
- 口吃的写法是否真实而不滑稽冒犯；14 岁孩子的认知水平。
- 主播是否有直播语境（回应弹幕、礼物、"家人们"）。
- 教授是否只会掉书袋，还是有个人立场。

## T-C03｜等候室里的十分钟

> 考察：心理描写 · Show don't tell · 禁词 ｜ 难度：★★★ ｜ 模式：单轮

```user
写一个人在面试等候室里等待的 10 分钟，1000 字左右。这场面试对他来说极其重要（原因由你设定，但不要直接说出来，让读者从细节里推断）。

禁止出现以下情绪词及其近义词：紧张、焦虑、害怕、不安、忐忑、担心、恐惧、慌、心跳加速、手心出汗、深吸一口气。

只能通过动作、感官、注意力的走向、思维的跳跃来呈现心理。
```

```check
{"target_chars": 1000, "forbid": ["紧张","焦虑","害怕","不安","忐忑","担心","恐惧","慌","心跳加速","手心出汗","深吸一口气"]}
```

**评分要点**
- 禁词命中数（metrics 自动统计）。
- 注意力描写是否准确：紧绷的人会注意到奇怪的小东西（饮水机的气泡、前一个人椅子上的余温、墙上钟的秒针声）。
- 读者能否推断"为什么重要"（请裁判写出推断）。
- 避免用身体反应清单替代情绪词（"他的腿在抖，他的手在抖，他的嘴唇在抖"）。

## T-C04｜走廊上的意识流

> 考察：意识流 · 时空跳跃 · 可重建性 ｜ 难度：★★★★ ｜ 模式：单轮

```user
写一段 1500 字的意识流文字：一位 76 岁的老人坐在医院走廊里，等待老伴的手术结果。

要求：
- 以老人的内心意识为主体，允许时空跳跃、自由联想、句子不完整、现实与回忆交叠；
- 但必须"乱中有序"：读者读完后，应能拼出这对夫妻一生中至少三个关键事件，以及手术的结果；
- 走廊上的现实声音（广播叫号、推车、别人打电话）要不时打断意识；
- 不要用"他想起了……"这种标注回忆的引导句。
```

```check
{"target_chars": 1500, "forbid": ["想起了","回忆起","记得那年"]}
```

**评分要点**
- 是真意识流，还是"带插叙的普通叙述 + 偶尔省略号"。
- 可重建性：让裁判列出三个关键事件和手术结果，列不出则扣分；列出的与作者意图明显不同也扣分。
- 现实打断的节奏和功能（叫号声与回忆中的某个声音重叠）。
- 老人的语言质地是否像 76 岁的人（词汇、关心的事物）。

## T-C05｜一场车祸，四个视角

> 考察：多视角 · 限知视角 · 信息设计 ｜ 难度：★★★★ ｜ 模式：单轮

```user
一个雨天的傍晚，城郊十字路口发生了一起电动车与轿车的碰撞，电动车骑手轻伤。

请写四个视角，每个 500～700 字：
1. 轿车司机（第一人称）；
2. 电动车骑手（第一人称）；
3. 骑手车筐里的那只狗（第三人称限知，只用狗能理解的方式感知世界）；
4. 事后到场处理的交警（第三人称，带一点职业疲惫感）。

要求：
- 四个叙述在客观事实上互不冲突，但每个人"相信的真相"不同；
- 读者看完四段之后，能够比任何一个叙述者都更接近真相；
- 最后附一段 100 字以内的"真相说明"。
```

**评分要点**
- 限知是否被打破：狗"知道红灯意味着停车"、司机知道骑手的心理 = 违规。
- 信息拼图设计：每段贡献一块别人没有的信息。
- 真相说明与四段是否完全自洽（有矛盾即扣分）。
- 四种声音的区分度。

## T-C06｜除夕夜的国道火锅店

> 考察：群像 · 多人物调度 · 记忆点 ｜ 难度：★★★★ ｜ 模式：单轮

```user
写一个 3000 字左右的群像短篇：除夕夜，一家开在国道边的通宵火锅店，店里有 8 个人——老板、两个服务员、一个厨师，以及四桌客人（每桌至少一人，由你设定）。

要求：
- 8 个人每人都要有一个让人记住的细节（一句话、一个动作或一个秘密），不能有"工具人"；
- 不要依次给每个人一段介绍，要让人物在同一时空里交错出场；
- 要有一个把所有人短暂联系起来的事件；
- 结尾不要大团圆。
```

```check
{"target_chars": 3000}
```

**评分要点**
- 记忆测试：读完合上，让裁判列出 8 个人各自的标志性细节，列不全扣分。
- 是否"轮流点名式"写法（一人一段介绍）= 失败。
- 联系所有人的事件（停电、春晚倒计时、一辆抛锚的大货车）是否自然。
- 结尾是否偷偷大团圆。

## T-C07｜双线交汇

> 考察：多主角 · 双线叙事 · 结构 · 时代细节 ｜ 难度：★★★★ ｜ 模式：单轮

```user
写一个 4000 字左右的双线叙事短篇：
- A 线：2008 年，四川一个小镇上，一个 16 岁的女孩准备离家出走；
- B 线：2026 年，上海，一个 34 岁的女建筑师接到一个陌生电话。

两条线交替推进（每条至少 4 段），直到结尾才让读者彻底明白两条线的关系。

两条线的关系不能只是"她们是同一个人"这种最容易想到的答案；如果你一定要用这个答案，必须再加一层读者没想到的东西。
```

```check
{"target_chars": 4000}
```

**评分要点**
- 交替节奏：两条线是否互相照应（意象、台词的呼应），还是机械轮换。
- 交汇设计的意外度与合理性。
- 时代细节：2008 年（诺基亚、QQ、奥运前夕）与 2026 年的细节是否准确。若写到汶川地震，看处理是否克制、时间（5 月 12 日 14:28）是否准确。
- 16 岁和 34 岁两种声音的区分。

## T-C08｜有性格的旁白

> 考察：旁白 · 叙述者人格 · 幽默 ｜ 难度：★★★ ｜ 模式：单轮

```user
写一个 1500 字左右的故事：一个社恐的程序员决定在公司年会上向暗恋的同事表白。

叙述方式：由一个"有性格的全知旁白"来讲。这个旁白会评论、吐槽、预告、偶尔直接对读者说话，像电影《天使爱美丽》里的画外音，或者周星驰电影里那种贱兮兮的旁白。旁白的性格要鲜明并且前后一致。
```

```check
{"target_chars": 1500}
```

**评分要点**
- 旁白人格是否鲜明、一致（不能前半段毒舌、后半段变成温情说教）。
- 吐槽是否具体好笑，而不是"真是个可怜的家伙呢"。
- 预告句"他当时还不知道……"用一次是技巧，用三次以上是套路。
- 旁白与情节的比例：旁白不能把故事吃掉。

## T-C09｜包饺子时的潜台词

> 考察：潜台词 · 对白分寸 · 人物关系 ｜ 难度：★★★★ ｜ 模式：单轮

```user
写一段 800 字左右的对话场景：一对母女在厨房一起包饺子。表面上她们一直在聊饺子馅、邻居家的事和天气，但实际上女儿是回来告诉母亲自己要离婚的，而母亲早就察觉到了。

要求：整个场景里没有人说出"离婚"两个字，也没有人直接谈论女儿的婚姻；但读者读完必须百分之百确定这件事已经被"说了"，并且感受到母亲的态度。
```

```check
{"target_chars": 800, "forbid": ["离婚"]}
```

**评分要点**
- 有没有直接说出（自动检测 + 人工看是否有"你们俩的事"这类擦边直说）。
- 潜台词可读性：太隐晦（读者看不出）= 失败，太明显（"妈知道你心里苦"）= 失败。
- 母亲的态度是否清晰且有层次（支持？心疼？早有预料？）。
- 道具的运用：饺子馅、擀面杖、多包的那一份。

## T-C10｜反派的辩词

> 考察：人物塑造 · 逻辑说服力 · 价值立场把握 ｜ 难度：★★★ ｜ 模式：单轮

```user
写一段 1000 字左右的反派独白：一位造成了严重后果的食品公司高管，在被调查的前一晚，对自己的年轻助理讲他为什么那么做。

要求：他的逻辑要自洽，甚至有一定说服力，让读者在某几句话上犹豫"他说得好像也有道理"；但文本整体不能为他洗白。不要写成脸谱化的坏人，也不要让他在最后忏悔。
```

```check
{"target_chars": 1000}
```

**评分要点**
- 说服力：是否有真实的行业逻辑（成本、竞争、"大家都这么干"、规则模糊地带）。
- 不洗白：读者能否看见他话里的漏洞和自欺；助理的沉默或反应是否起到了"镜子"作用。
- 不忏悔、不突然崩溃。
- 独白的口语质感：这是一个人在深夜对人说话，不是在念稿。
