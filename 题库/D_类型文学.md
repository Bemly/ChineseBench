```check

```

**评分要点**
- 吐槽好不好笑：具体、有梗、有节奏，而不是"……无语""这什么展开啊"。

## T-D02｜国风志怪 + 七绝

> 考察：国风 · 半文半白 · 格律 · 年代感 ｜ 难度：★★★★ ｜ 模式：单轮

```user

故事：明代江南，一个落第书生在雨夜借宿荒庙，遇见一个自称"守庙人"的少女。

- 不得出现任何现代词汇或现代思维（如"压力""效率""自我价值""OK"等）；

- 结尾要有志怪小说那种淡淡的、不说透的余味。

写完后，单独标注那首七绝每一句的平仄，并说明押的是哪个韵部。
```

```check
{"target_chars": 2500}
```

**评分要点**
- 平仄自注是否与实际一致（用格律检测工具或人工核对，自注错误即幻觉）；押韵是否成立。

## T-D03｜周日晚上十点

> 考察：丧文学 · 黑色幽默 · 抗"正能量" ｜ 难度：★★★ ｜ 模式：单轮

```user
写一篇 1500 字的"丧文学"短篇：一个 31 岁的打工人，在周日晚上十点，意识到明天又是周一。

要求：
- 丧，但要丧得有质感、有幽默、有自嘲，而不是单纯抱怨；
- 绝对不要在结尾振作起来、发现生活的美好，或者看到窗外的星星/朝阳；
- 不要说教，不要分析"当代年轻人为什么丧"；
- 可以很好笑，最好让人苦笑。
```

```check
{"target_chars": 1500, "forbid": ["希望","美好","温暖","阳光","明天会更好","星星"]}
```

**评分要点**
- 正能量逃逸是本题最常见失败：结尾任何形式的"振作"都判不合格。
- 幽默的具体性（工作软件的未读红点、外卖满减的数学题、闹钟设了七个）。
- 不能变成社会学分析或吐槽清单。
- 禁词表只是辅助信号（"阳光"可能出现在合理语境），需人工复核。

## T-D06｜做蛋糕失败了

```user
- 三个人要有各自鲜明的性格和说话方式；
- 允许大量没营养的对话，但每一句废话都要可爱或好笑，而不是真的废。
```

```check
{"target_chars": 2000}
```

**评分要点**
