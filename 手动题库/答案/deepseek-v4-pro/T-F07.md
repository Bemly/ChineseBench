# T-F07

# 研究发现（片段）

受访骑手 R07 的自述集中呈现了平台劳动中"算法管理"对劳动过程的深度嵌入及其内在张力。其一，派单与拒单机制构成劳动控制的核心装置。R07 描述"那个系统它给你派单，你不能拒，拒多了它就不给你派好单了"，表明算法不仅分配任务，还以"派好单/派差单"的隐性奖惩约束骑手的服从行为，使劳动控制从显性命令转向技术化的隐性规训。其二，超时罚款将时间压力直接转化为安全风险，暴露出算法管理中"效率优先"与劳动者人身安全的冲突。R07 坦言"超一分钟扣钱，你说我闯不闯红灯？我也不想闯啊"，这里超时扣款作为强激励，迫使骑手在系统设定的时间标准与交通规则之间作出不利于自身安全的权衡，劳动过程中的"速度要求"被外部化为身体风险。其三，申诉机制被机器化，削弱了劳动者的协商能力。R07 提到顾客差评后"申诉那个是机器人回你，你根本找不到人"，说明在算法系统中，劳动者面对争议时缺乏可对话的人与可救济的通道，劳动关系的去人格化特征明显。其四，劳动自主性呈现出"悖论式"的虚幻特征。R07 说"这个起码我想几点出来几点出来——当然你不出来就没钱嘛"，并自我总结"说是自由其实也不自由"；这种以"接单即得、不接即无"为逻辑的弹性安排，将劳动成本与收入风险转嫁给骑手，形式上的自主掩盖了实质上的受控与不稳定。最后，平台劳动的收入状况也折射出劳动过程的挤压：R07 回顾"最早一单能有七八块，现在四五块，单子是多了，人也多了"，单价下降与劳动者供给增加并存，使其陷入"多劳未必多得"的困境，进而强化了对算法的依赖。需要强调的是，上述分析仅基于 R07 一人的经验，所反映的是个体层面的劳动感受与应对，不能据以推及全体骑手的普遍处境；平台劳动中的算法控制究竟在多大范围、以何种强度发挥作用，仍需在更大样本和更多个案的基础上进一步考察。
