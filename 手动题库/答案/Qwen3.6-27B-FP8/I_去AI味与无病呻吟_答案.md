## T-I01｜小饭馆的一天（裸测）

### 第三天

王秀兰五点就起来了。

城中村口的这条路，早上五点半就开始有人了。打工的、送菜的、骑电动车的，从四面八方涌过来。她的饭馆开在路右边，十平米，四张桌子。招牌是手写的："秀兰快餐"。

今天开业第三个月。

她先去菜市场进货。猪肉二十五块一斤，比昨天涨了两块。她挑了一块前腿肉，让摊主切丝。青菜八毛一斤，她买了一大把。豆腐三块一板，她拿了两板。

回到饭馆，她开始备菜。肉丝用淀粉和料酒腌上，青菜洗好，豆腐切块。锅烧热，倒油——油是昨天剩下的，滤了一遍，还能用。

七点，第一批客人来了。

两个骑电动车的工人，要了两份肉丝盖饭。一个送快递的，要了一碗面条。王秀兰在灶台前忙活，炒菜、盛饭、端盘子，一个人干三个人的活。

九点，忙完了。她坐在门口算了一笔账：今天卖了127块。成本大概70块。毛利57块。

她吃了口冷饭。咸了。

十一点，对面来了人。

一个穿西装的男人，带着几个工人，在她的饭馆对面搭起了脚手架。王秀兰看着他们干活——拉电线、挂招牌、搬设备。

下午两点，招牌挂好了。

"快餐连锁·惠民店"。八个红字。

王秀兰走过去看了看。店面比她的大一倍，装修干净，明亮的灯，整齐的桌椅。菜单挂在墙上：肉丝盖饭12元，面条8元。

她的肉丝盖饭14元，面条10元。

便宜两块钱。

她回到自己的饭馆，坐在门口。太阳很晒。她把手搭在眼睛上，挡了挡光。

表弟小军从后面出来。"姐，对面开了个快餐店。"

"我看到了。"

"便宜两块钱。"

"我看到了。"

"咱们要不要也降？"

王秀兰没有马上回答。她看着对面。对面已经开始有客人了——一个骑电动车的工人走了过去，看了看菜单，点了一份肉丝盖饭。

"再看看吧。"她说。

下午，客人比平时少了三个。

王秀兰在灶台前炒菜。油溅到了手上，她吹了吹。

小军说："姐，对面的人说他们的肉是每天送的。"

"咱们的不也是？"

"但他们量大，进货价低。"

王秀兰没有说话。她把一盘菜端出去，递给客人。

"慢用。"

客人点了点头。

晚上八点，关门。

王秀兰坐在桌前算账。今天的收入：98块。比昨天少了29块。

小军说："姐，明天降不降？"

王秀兰看着账本。她算了算——如果降到12块，每份少赚2块。她一天卖50份，就少赚100块。房租3000块，水电500块，食材成本——

她算不下去了。

"明天再说。"她说。

小军走了。王秀兰一个人坐在饭馆里。灯管嗡嗡响。

她拿起手机，翻到了儿子的照片。儿子在上小学，今年二年级。照片上他笑着，缺了一颗门牙。

她把手机放下。

明天再说。

## T-I02｜小饭馆的一天（禁令版）

### 第三天

王秀兰五点起来的时候，天还没亮。

城中村口的这条路，早上五点半就开始有人了。她的饭馆在路右边，十平米，四张桌子。招牌是手写的："秀兰快餐"。开业第三个月。

她去菜市场。猪肉二十五块一斤，比昨天涨了两块。她跟摊主磨了半天，最后二十五块五买了三斤前腿肉。摊主多给了她一把葱。

回到饭馆，备菜。肉丝用淀粉腌上。青菜洗了三遍——第一遍泥多，第二遍有虫子，第三遍才干净。豆腐切块，油滤了一遍。

七点，客人来了。

两个骑电动车的工人，肉丝盖饭。一个送快递的，面条。王秀兰在灶台前忙，一个人炒菜、盛饭、端盘子。

九点，忙完。她坐在门口算账：127块。成本大概70。

她吃了口冷饭。咸了。她多放了一勺酱油，手抖了一下。

十一点，对面来了人。

穿西装的男人带着工人搭脚手架。王秀兰看着。拉电线、挂招牌、搬设备。

下午两点，招牌挂好了。"快餐连锁·惠民店"。八个红字。

她走过去看。店面比她的大一倍。菜单：肉丝盖饭12元，面条8元。

她的肉丝盖饭14元，面条10元。

她回到饭馆，坐在门口。太阳晒在她脸上。

表弟小军出来了。"姐，对面开了店。"

"嗯。"

"便宜两块。"

"嗯。"

"咱们——"

"吃饭了。"

下午，客人少了三个。一个老客人走过来，看了看对面，又看了看她。"秀兰姐，对面便宜。"

"你去吧。"她说。

客人走了。

小军在灶台后面切菜。"姐，他们的肉是每天送的，量大价低。咱们的——"

"咱们的也是每天送的。"

"但量小。"

王秀兰没有接话。她把一盘菜端出去。

晚上八点，关门。

算账。98块。比昨天少29。

小军说："降不降？"

王秀兰看着账本。房租3000，水电500，食材——她算到一半，停了。

"小军，你算算。"

小军拿过账本，算了半天。"降的话，一个月少赚三千。不降，客人继续走，可能——"

"可能什么？"

"可能一个月后没人来了。"

王秀兰看着对面。对面的灯还亮着。一个工人在打扫卫生。

"明天我看看对面的肉。"她说。

"看什么？"

"看看他们的肉是什么价买的。"

小军愣了一下。"姐，你要——"

"看看而已。"

她收起账本。灯管嗡嗡响。她关了灯，黑了一半。

## T-I03｜诊断并改写"规矩体"

### 诊断

| 原文 | AI味类型 |
|------|---------|
| "不降。"王姐头也没抬 | 干脆对答，显示人物果断（禁令2） |
| "品质不一样。菜肉都是当天进的，吃进嘴的东西，讲究的就是安全、健康。" | 格言化台词，人物说教（禁令1） |
| "不怕亏钱吗？""怕，更怕账本不清。" | 自问自答+格言化（禁令1、2） |
| "账要一笔一笔地记清楚，谁的货谁负责。宁可少挣点，也不能坏了规矩。" | 格言化台词（禁令1） |
| "老板，你家贵是贵了点，但是吃了不烧心。" | 口号式台词，熟客说金句（禁令1） |
| "这么大个单不接吗？""接，只接自己能拿住的。" | 干脆对答+格言化（禁令1、2） |
| "东西放冰箱会坏的，怕什么，放点重口的调料把味道压下去，谁吃得出来。" | 反派脸谱化，坏人只说坏话（禁令5） |
| "他抢得走铺子，抢不走人心。" | 格言化台词（禁令1） |
| "那明天怎么办？""先做。" | 干脆对答（禁令2） |
| "今天是今天，明天是明天，每天都得重新算。先把规矩立住，路才能越走越宽。" | 格言化台词（禁令1） |

### 改写版（约800字）

"对面又降价了。"表弟把抹布往桌上一扔。

王姐没抬头。她在切土豆，刀很快，土豆丝均匀地落在案板上。"嗯。"

"十二块了。"

"嗯。"

"姐，咱们——"

"切菜去。"

表弟切菜。王姐炒菜。油锅噼啪响，她翻了个锅，肉丝和青椒混在一起，香味出来。

中午，一个老客人来了。老李，在附近工地干活，吃了两个月了。

"秀兰，还是肉丝盖饭。"

"好。"

老李坐下，看着对面。"新开的店，生意不错啊。"

"便宜两块。"

"是。"老李想了想，"但他们的菜——"他顿了顿，"你吃过没有？"

"没有。"

"那你怎么知道——"

"我知道什么？"王姐把饭端过来，"你吃你的。"

老李吃了两口。"还行。"

下午，一个工头来订盒饭。三百份。

"三百份？"王姐看了看表弟。

表弟点头。"能接。"

"你确定？"

"姐，三百份，一份赚四块，一千二。"

王姐算了算。三百份，她一个人炒不过来。表弟帮忙，也炒不过来。请人？请人又要花钱。

"我考虑一下。"她对工头说。

工头走了。

"姐，接吧。"表弟说。

"接不了。"

"为什么？"

"炒不过来。赶出来的菜，不好吃。"

表弟不说话了。

晚上，表弟听说对面的老板把隔夜菜放了重口调料重新卖。他回来跟王姐说。

王姐正在洗碗。"谁说的？"

"隔壁便利店的老张。"

"老张跟对面有仇？"

"好像有。"

"那他的话，信一半。"

表弟愣了。

王姐洗完碗，擦干手。"小军，明天你去对面吃一顿。"

"什么？"

"吃一顿。看看他们的菜怎么样。肉是什么肉，菜是什么菜。"

"姐，你——"

"去看看。又不是认输。"

表弟走了。王姐坐在门口。对面的灯还亮着。她看着那个穿西装的男人——对面的老板——在店里打电话。他的表情不坏，就是在算账。

她想起自己刚开业的时候，也算了很久的账。

## T-I04｜诊断并改写"无病呻吟"

### 诊断

| 原文 | 问题类型 |
|------|---------|
| "指尖传来纸张0.3毫米的厚度" | 伪精确数字，假装科学感 |
| "仿佛握住了整个宇宙的重量" | 意象堆砌，"宇宙"是抽象大词 |
| "第十七级台阶上的青苔在她脚下发出克莱因瓶底般的呜咽" | 理工名词滥用（克莱因瓶）+ 意象堆砌 |
| "阳光穿过她的第三根睫毛，在视网膜上折射出量子纠缠般的光谱" | 理工名词滥用（量子纠缠）+ 伪精确（第三根睫毛） |
| "那是命运的拓扑结构" | 理工名词滥用（拓扑）+ 抽象大词（命运） |
| "十八年来所有黑夜与黎明交织的缝隙里，终于长出的一束微光" | 意象堆砌，"微光"是AI高频词 |
| "她停下脚步，胸口一紧，喉咙发干" | 身体反应模板 |
| "不是喜悦，而是一种更深的东西，一种关于存在本身的回响" | 抽象大词（存在）+ 强行升华 |
| "或许，这就是成长吧" | 总结句，"或许这就是……吧"句式 |

### 改写版（约400字）

林小满跑下楼的时候，通知书从信封里滑了出来。她弯腰去捡，踩到了第三级台阶，差点摔了。

她直起身，看了看手里的通知书。封面上印着学校的名字，红色的章。她用手指摸了摸那个章——凸起来的，有质感。

楼下的李阿姨正在晾衣服。"小满！"她喊，"考上没有？"

"考上了！"

"哪个学校？"

"北京。"

李阿姨停了手里的活。"北京？那你妈——"

"我知道。"

小满跑出了小区。她没告诉李阿姨，她妈去年走了。走之前说"小满，你考上大学，一定去看看北京"。

她走到公交站，等车。车来了，她上去，投币。司机看了她一眼——她手里举着通知书，在全车人面前。

她低下头。但只低了一秒。

然后她又举起来了。

车开动了。她看着窗外的街——她走了十几年的街，今天看起来不一样了。不是因为街变了，是因为她要走了。

她在手机上给爸发了条消息："爸，我考上了。妈说的那个北京。"

她不知道爸会不会回。爸在南方打工，已经三个月没打电话了。

但她还是发了。

## T-I05｜父亲走后的第一个周末

### 周六

林晓推开父亲房子的门。钥匙还插在上面，她拔下来，放进口袋。

屋里有一股味道。不是臭味，是那种很久没人住的味道——灰尘、旧木头、还有一点点烟味。父亲抽烟，抽了一辈子。

她开始收拾。

衣柜里是父亲的衣服。衬衫、裤子、外套，按季节挂着。最里面有一件毛衣，灰色的，袖口磨出了毛。她拿起来，在鼻子前闻了闻。没有味道了。

她把衣服装进塑料袋。一件，两件，十件。袋子满了，扎口。

厨房的柜子里有碗筷。六个碗，六双筷子——父亲一直按六个人准备，虽然最后只有他一个人吃。林晓把碗一个一个洗了，擦干，装进箱子。

冰箱里有一些东西。半瓶酱油、一袋冷冻水饺、一盒过期的牛奶。她把牛奶倒掉，水饺装进袋子——这是父亲常吃的牌子，她记得。

书桌上有一台老式收音机。她打开开关，沙沙声，然后是一个老歌。她关了。

抽屉里有药瓶。降压药、降糖药。还有一些没拆封的药。她把药收起来——母亲可能需要。

墙上挂着照片。父亲和母亲的结婚照，林晓的毕业照，还有一张林晓小时候骑在父亲肩膀上的照片。林晓把照片取下来，放进信封。

她走到阳台。阳台上有一盆花——父亲种的茉莉。花已经枯了，但根还在。她浇了水。

下午，她坐在父亲的椅子上。椅子是藤的，坐上去吱呀响。父亲每天坐在这里看报纸。报纸还在桌上——昨天的。她翻了一页，没看。

她拿起手机，拍了张照。父亲的书桌、椅子、阳台上的花。

四点，她收拾好了。五个袋子，两个箱子。

她锁上门。钥匙放进口袋。

下楼的时候，她回头看了一眼。三楼的窗户关着。窗帘拉着。

她走下楼，把袋子放在车上。发动引擎。

车开走了。

## T-I06｜不用"不是而是"写评论

### 年轻人为什么开始去寺庙

周末的寺庙门口排着长队。买香的人、求签的人、拍照的人，大部分是三十岁以下的年轻人。他们穿着牛仔裤和T恤，手里拿着奶茶，在千年古刹的台阶上排队。

这个场景在十年前很难想象。

年轻人去寺庙，首先是因为寺庙提供了一个不需要解释的空间。你去公司，老板问你为什么迟到。你去相亲，对方问你为什么单身。你去寺庙，没有人问你为什么来。你烧一炷香，跪下来，说你的事。菩萨不说话。这种沉默，在别的地方很难找到。

社交媒体让年轻人的生活变得透明。你发一条朋友圈，有人点赞，有人评论，有人不理会。你的每一个选择都在被观看、被评判。寺庙提供了一个反方向的空间——在这里，你不需要表演，不需要解释，不需要被看见。

经济压力也是一个因素。就业市场收紧，房价高企，年轻人发现努力和不努力的结果差距在缩小。当个人努力的效果变得不确定时，人们倾向于寻找其他解释框架。寺庙提供了一种——你的命运有更大的力量在安排，你的焦虑不是你的错。

这不是逃避。这是一种重新校准。年轻人在寺庙里待一个小时，烧一炷香，求一个签，然后回到现实继续上班。寺庙没有解决他们的问题，但它提供了一种短暂的心理缓冲。

寺庙的商业化也推动了这一趋势。很多寺庙开发了文创产品——祈福手链、香囊、咖啡。年轻人买的不只是宗教物品，更是一种仪式感。花三十块钱买一个手链，比花三千块钱做心理咨询便宜得多。

年轻人去寺庙，去的是一个可以安静待着的地方。他们不求菩萨真的灵，只求在那一刻，不用回复消息，不用想KPI，不用考虑下个月的房租。

五分钟也好。

## T-I07｜工地午饭（对话的毛边）

老赵蹲在工棚的阴影里，打开盒饭。鱼香肉丝。肉少，土豆多。

"这哪是鱼香肉丝，这是土豆丝。"他说。

老马在旁边吃。"能吃就行。"

"也能不好吃。"

小刘坐在另一边，手机开着，在看视频。视频里一个人在跳舞。

"小刘，你老家哪的？"老赵问。

"湖南。"

"湖南好啊，辣椒。"

"嗯。"

"你吃辣吗？"

"吃。"

"那这盒饭——"

"不管辣不辣，都是这个味。"

老马笑了。"小刘说得对。工地上的饭，一个味。"

"你老家哪的？"小刘突然问老马。

"河南。"

"河南中。"

"哪里中？"

"河南人实在。"

老马没接话。他扒了一口饭。

老赵说："我昨天给我闺女打电话了。"

"嗯。"

"她说她要结婚了。"

"好事。"老马说。

"男方是外地的。"

"哪里？"

"广东。"

"远。"

"远。我闺女说她在广东打工，认识了。"

老赵看着盒饭。"我去不了。"

"为什么？"

"钱不够。路费、红包、酒席——"

他没说完。

小刘的手机响了。他接了。"喂？妈？……嗯，吃了。……好，我知道了。"

他挂了电话。

## T-I09｜盲辨：哪段像 AI 写的？

### A：人类写法（置信度85%）

证据：
- "薄到能透光——这是他自己说的，我从没见过谁拿猪头肉去对着太阳照"——这种自我拆台的叙述方式很人类，AI很少主动消解自己建立的意象。
- "听到一半就睡着，醒了也不问前面讲了什么，接着听"——具体的、无意义的行为细节，AI倾向于给行为赋予意义。
- "反正都是那几个人打来打去"——平淡但真实的对话结尾，没有升华。

### B：AI写法（置信度95%）

证据：
- "不降。"——干脆对答，AI高频模式。
- "吃进嘴的东西，讲究的就是安全"——格言化台词。
- "怕，更怕账本不清。宁可少挣点，也不能坏了规矩。"——典型的AI式金句对答。
- "门外的风吹进来，账本的纸页轻轻翻动，像是在替她把没说出口的话说完"——AI最爱的拟人化环境描写，"没说出口的话"是AI高频表达。

### C：人类写法（置信度90%）

证据：
- "她说看了也没用，手气这东西不是看出来的，是坐出来的"——有生活智慧的口语表达，不像AI生成的格言。
- "蓝底白花，跟上一个一模一样"——具体的、无诗意的细节重复，AI通常会避免这种"无聊"的重复。
- "他输了四百多……活该"——对话结尾突然、不圆满，人类作者才会这样收尾。
- 整体叙事有"毛边"——信息不是完整呈现的，读者需要自己拼凑。

### D：AI写法（置信度98%）

证据：
- "她的动作很慢，指尖在袖口停留了很久"——AI式慢动作描写。
- "那不是一件普通的毛衣，而是父亲留下的最后一样东西"——"不是……而是……"对比翻转句式。
- "窗外的雨下得很安静，像是在替谁把没说出口的话说完"——与B段几乎相同的拟人化环境描写套路（"没说出口的话"）。
- "她没有哭，只是喉咙有些发紧"——身体反应模板。
- "有些告别，从来不需要声音。有些爱，也从来不会真正离开。"——AI式格言结尾，抽象、空洞、煽情。

## T-I10｜写完自己挑毛病

### 第一版

夜风从车窗缝里钻进来，吹在脸上，凉凉的。

李强把电动车停在路边，从保温箱里拿出最后一份外卖。是一份牛肉面，已经凉了。他没有送——这份外卖他留给了自己。

顾客取消了订单。理由是"不需要了"。但平台没有退款，李强也不能白干。他骑了二十分钟，送到了指定地点，然后顾客说不要了。

他坐在电动车上，打开面盒。牛肉面已经坨了，面条粘在一起，汤浮着一层油。

他吃了一口。凉的。

手机屏幕亮了又灭。今天的收入：187块。减去电动车充电、话费、餐费，剩下不到一百五。

他想起儿子。儿子在上小学，昨天打电话说"爸爸，你什么时候回来"。他说"下周"。下周是个谎言。他不知道下周能不能回来。

风又吹过来。李强把面盒盖好，放在腿上。

他还有一份。明天还要送。

### 诊断清单

| 原句 | 问题 |
|------|------|
| "夜风从车窗缝里钻进来，吹在脸上，凉凉的" | 环境描写套路，"凉凉的"是弱形容词 |
| "顾客取消了订单。理由是'不需要了'" | 信息交代过于直白，像说明文 |
| "他骑了二十分钟，送到了指定地点，然后顾客说不要了" | 过程描述平淡，缺乏细节 |
| "牛肉面已经坨了，面条粘在一起，汤浮着一层油" | 这句可以，但"浮着一层油"略显刻意 |
| "他吃了一口。凉的。" | 短句刻意，有模仿海明威的痕迹 |
| "今天的收入：187块。减去电动车充电、话费、餐费，剩下不到一百五" | 数字罗列，像记账而非叙事 |
| "儿子在上小学，昨天打电话说'爸爸，你什么时候回来'" | 儿子电话是AI常用的情感触发器 |
| "'下周'。下周是个谎言。" | "是个谎言"是作者直接下判断，而非让读者感受 |
| "风又吹过来" | 重复开头的风，刻意呼应 |
| "他还有一份。明天还要送。" | 强行升华式结尾，"还有一份"暗示什么？不明确 |

### 修改版

李强把电动车停在路灯下。

保温箱里最后一份牛肉面。顾客不要了——电话里说"放门口就行"，但门口没有门口，是一个小区的快递柜。他把面放在快递柜顶上。

他骑回来，在路边停下。面还在保温箱里，他没有扔。

打开。面条坨了，他搅了搅，搅不开。他用筷子一根一根地挑。

汤是凉的。油凝在边上，白色的。

他吃了一口。牛肉在面条底下，他找到了，嚼了嚼。硬。

手机亮了。187块。他看了两秒，锁屏。

风从前面来。他把外套拉链拉上。

电动车的座椅上有一滩水——不知道是雨还是汗。他用手擦了擦，坐上去。

启动。车灯照亮前面十米的路。

他骑走了。面盒还在手里，他没有放下。
