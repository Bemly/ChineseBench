# T-D16｜甲申年三月十九日

崇祯十七年，三月十九，卯时。

天还没亮透，紫禁城上空有很厚的云，风从北面来，带着煤渣和马粪的味道。我叫小栓子，今年十七，净身进宫五年，在司礼监外围的惜薪司当差，平时管的是宫里的炭火——哪宫要炭，多少斤，几时送，我记账。

昨儿夜里，宫里就乱了。听说闯军已过了广渠门，外城陷了，内城也快守不住。钟鼓楼的钟敲了一夜，不是报时，是警钟。王承恩公公——司礼监掌印，皇爷身边最得用的人——从乾清宫出来时，脸白得像纸，对我们几个小太监说："都机灵着点，今儿个不管听见什么、看见什么，别乱跑，也别乱说话。"

我哪敢乱跑？我连紫禁城的门朝哪开都快忘了。进宫五年，只出过一次宫，还是去西山拉炭。

卯时初，我按例去乾清宫送炭。往常这时候，宫门已开，宫女们端着水盆进出，但今儿个，乾清宫门紧闭，门口站着两个锦衣卫，刀抱在怀里，眼神很凶。我不敢近前，只得把炭筐放在阶下，轻声问："公公，炭……还送进去吗？"

一个锦衣卫看了我一眼，摆摆手："放这儿吧，别进去。"

我放下炭筐，转身要走，却听见殿内传来很低的说话声，像是皇爷的声音，哑的："……朕非亡国之君，事皆亡国之臣……"

还有王承恩公公的声音，带着哭腔："万岁爷，奴婢伺候您去……"

我不敢听，快步退到廊下，蹲在柱子后，心跳得像要从嗓子眼里跳出来。

辰时，天亮了，但亮得很浑，像蒙了一层黄沙。宫里的人开始跑，有宫女抱着包袱往西跑，有太监往东跑，撞在一起，也不说话，只管跑。我看见尚膳监的刘公公，平时最体面的一个人，这会儿帽子都丢了，提着袍子跑，袍子被门槛绊了一下，摔在地上，半天爬不起来，也没人扶。

我也想跑，但往哪跑？宫外全是闯军，听说闯军进城后要"拷掠"，有钱的要被夹棍夹。我一个小太监，没钱，但听说他们也抓太监，说太监是"阉党"，要杀。我腿软，蹲在廊下动不了，只觉得炭筐里的炭，像要烧起来一样烫。

巳时，风更大了。我壮着胆子，往煤山方向看——煤山在紫禁城北面，不高，但能看见全城。隐约听见城外的喊杀声，像潮水，一阵一阵。有小太监从北面跑来，边跑边喊："破了！破了！齐化门破了！闯军进城了！"

喊声像刀，把最后一点撑着宫里的东西也割断了。更多人跑起来，连平时最讲规矩的老太监也跑了。我看见一个老宫女，坐在台阶上哭，手里抱着一个小木盒，不知道装的什么，嘴里念着："娘娘，娘娘……"

我认得她，是坤宁宫的。坤宁宫是皇后娘娘住的地方。

午时前后，宫里忽然安静了一下，像风暴前的那一瞬。我听见乾清宫方向传来一声很闷的响，像是什么倒了，又像是门被风撞上。随后，王承恩公公从里面出来，眼睛红肿，对廊下的几个太监说："皇爷……皇爷去了煤山……"

没人敢问"去了"是去做什么。我们都懂。

有几个胆大的太监，跟着王公公往煤山去了。我没敢跟，我怕看见什么，也怕被闯军撞见。我缩在惜薪司的柴房里，把门抵住，从门缝往外看。

未时，闯军进宫了。不是从正门，是从东华门、西安门涌进来，穿着各色衣裳，有盔甲的，也有布衣的，手里拿着刀枪，见人就问："崇祯在哪？皇后在哪？太子在哪？"有太监被抓住，问不出，就被推到一边，刀架在脖子上。

我躲在柴房里，连呼吸都不敢大声。听见外面有闯军踹门的声音，一间一间搜。我把身子缩进柴堆里，用炭灰抹在脸上，手里紧紧攥着那本记炭的账本——那是我唯一的东西，五年里，每一笔炭的出入我都记着，字写得工整，像是我在这宫里存在过的证据。

搜到惜薪司时，门被踹开了。一个闯军探头进来，看见一堆柴，没细看，又关门走了。我听见他在外面喊："这没人，全是炭！"

他们走了，脚步声远了。

我等了很久，才从柴堆里爬出来，身上全是炭灰，像个黑人。我推开门，外面天已近黄昏，紫禁城的琉璃瓦在暮色里发着暗黄的光，像要沉到地里去。

我往煤山方向走，腿像灌了铅。煤山不高，几步就到了。山上有棵老槐树，树下……我不敢细看，只看见有两个人影，一高一矮，高的穿着明黄，矮的穿着蓝，都挂在树上，随风轻轻晃。旁边有几个闯军围着，指指点点。

我转身就跑，跑回惜薪司，关上门，坐在炭堆上，抱着那本账本，哭了。不是大声哭，是憋着哭，肩膀抖，像筛糠。

夜里，宫里到处是火光和喊声。我不知道太子、二王去了哪里，也不知道皇后娘娘怎样了——后来才听说，皇后自缢于坤宁宫，长公主被皇爷砍伤了手臂，太子在乱中逃出，不知所踪。

我一个小太监，能做什么？只有把那本账本抱得更紧，好像抱住了，我就还是惜薪司的小栓子，明天还要去送炭，后天还要记账，日子还能像以前那样，一笔一笔，清清楚楚。

但炭已经没人要了，账本上的字，也像要被炭灰盖住，再也看不清了。

### 史实与虚构说明

**真实史实部分：**

1.  时间地点：1644年农历三月十九日（公历4月25日），北京城破，崇祯帝自缢于煤山（今景山），此为明史定论。
2.  崇祯结局：崇祯帝在煤山自缢，随行太监为司礼监掌印王承恩，二人自缢于一株槐树（后称"罪槐"），史料见《明史·庄烈帝纪》《国榷》。
3.  闯军破城：李自成部于三月十九日凌晨攻破外城，午后破内城，经齐化门（今朝阳门）、彰义门等入城，城内混乱，太监、宫女四散奔逃。
4.  宫廷制度与称谓：司礼监、惜薪司为明代宦官二十四衙门之一，掌印、秉笔等职衔符合明末宦官体系；皇帝称"皇爷""万岁爷"、太监自称"奴婢"符合当时宫内用语。
5.  坤宁宫皇后自缢、长公主被崇祯砍伤、太子出逃等情节，均有史料记载（《明史·后妃传》《甲申传信录》），长公主即朱媺娖，后为清初"长平公主"传说原型。
6.  "朕非亡国之君，诸臣皆亡国之臣"为崇祯煤山自缢前所书遗言或口谕，见多种明末笔记。

**虚构部分：**

1.  主角"小栓子"为虚构小人物，惜薪司小太监身份为艺术虚构，用以承载底层视角，其经历、心理活动及柴房躲藏情节均为虚构。
2.  具体时辰的细节对话（如与锦衣卫、王承恩的简短交流）为合理想象，旨在还原氛围，并非实录。
3.  账本、炭筐、柴房躲藏等细节为虚构的生活化情节，用于体现小人物在历史洪流中的无力与自保。
4.  部分次要人物（如尚膳监刘公公、坤宁宫老宫女）为虚构群像，不指涉具体历史人物。


夜更深时，闯军的搜查过去了，宫里又安静下来，但那种安静是死一般的安静，连风声都像被捂住了嘴。

我从柴房出来，摸回惜薪司的库房，想找点吃的。库房里还有半袋子粟米，是给宫女们熬粥剩下的。我抓了一把，干嚼，嚼得牙疼，但咽下去，肚子里有了东西，就不那么慌了。

库房角落里，有一面小铜镜，是前任掌事太监留下的，平时没人敢照——太监照镜子，总觉得照见的是个不全的人。但今夜，我拿起那面镜子，对着昏暗的光，看了看自己——脸上全是炭灰，头发散了，眼睛红肿，像个小鬼。

我把镜子放下，想起王承恩公公临去煤山前，回头看了我们一眼，那一眼里，有怜悯，也有决绝。他跟了皇爷一辈子，最后也跟着皇爷去了。我们这些小太监呢？跟着谁去？

没有谁。只能跟着命。

我把粟米袋扎紧，把账本揣进怀里，找了个柴堆后的角落，蜷起来，像猫一样。宫外的喊杀声还在，但离我很远，像另一个世界的事。

我想，明日天亮，闯军会不会再来搜？会不会分粮食？会不会……不管怎样，活过今夜再说。

 coal山的槐树下，那两个人影还在晃，但我不再去看。我只听见自己的心跳，咚、咚，像那本账本里，一笔一笔的炭，虽轻，却是我活过的证据。
