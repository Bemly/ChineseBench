# T-I03｜诊断并改写“规矩体”

> 题目简述：诊断原文AI味并归类，改写约800字保留情节（降价之争、对面抢生意、坚持当天进货、拒接大单、最后决定搬店），对话有活人感。

---

### 一、逐句诊断

| 原句 | 问题归类 | 说明 |
|---|---|---|
| “王姐，对面又降价了。”表弟把抹布往桌上一扔。 | 尚可，功能性开场 | 动作符号化（扔抹布）是AI常用“着急”标签，但尚属正常。 |
| “不降。”王姐头也没抬，“品质不一样。菜肉都是当天进的，吃进嘴的东西，讲究的就是安全、健康。” | **格言化台词 + 正确废话 + 人物完美** | “品质不一样”“安全健康”是AI经营文万能口号，没有具体信息（什么菜、怎么进、成本多少），纯表态。真人会说“今早猪肉六块二进的，他家用冻货我咋降”。头也没抬是“冷静人设”标签。 |
| “不怕亏钱吗？”“怕，更怕账本不清。” | **自问自答式格言 + 对比翻转** | 典型的“怕，更怕……”AI金句结构。把复杂的经营焦虑压缩成一句对仗口号，账本不清与亏钱根本不是同一维度，强行对立显得深刻。 |
| “账要一笔一笔地记清楚，谁的货谁负责。宁可少挣点，也不能坏了规矩。” | **格言体密集爆发** | 两句都是可直接抄进笔记本的“生意经”。AI味最重的一句，真老板不会在后厨跟亲戚讲这种话，只会说“昨儿那笔西红柿钱还没对上”。 |
| 门口进来一个熟客，笑着说：“老板，你家贵是贵了点，但是吃了不烧心。” | **工具人捧哏 + 对比翻转句** | 熟客功能就是来肯定主角。句式“贵是贵了点，但是……”是AI最爱的让步转折，用来给主角颁奖。真熟客会说“你家就是油少点，吃着不腻”。 |
| 王姐点点头，没说话。 | **沉默美化** | 用沉默代替反应，塑造“沉稳、不争辩”的完美形象。真人要么笑笑说“谢谢啊”，要么趁机抱怨两句对面。 |
| “这么大个单不接吗？”“接，只接自己能拿住的。” | **问答干脆体 + 格言体** | “接，只接……”是AI最爱用的一两个字干脆对答+格言收尾，显得果断有原则。实际上300份盒饭对小馆是算产能、算人手的账，不是原则问题。 |
| 晚上，表弟听说对面的老板把隔夜菜放了重口调料重新卖：“东西放冰箱会坏的，怕什么，放点重口的调料把味道压下去，谁吃得出来。” | **反派脸谱化 + 口号式自白** | 对面老板像AI生成的坏人NPC，主动把坏事用台词说出来，逻辑愚蠢（冰箱放不坏还要压味？）且语言书面化。真黑心老板不会这么说，只会偷偷做。 |
| “他抢得走铺子，抢不走人心。” | **格言体顶峰** | 纯口号，可做抖音封面。空洞，无任何经营信息，人心怎么来、怎么算，完全不提。 |
| “那明天怎么办？”“先做。” | **问答干脆体 + 玄虚回答** | 又一次一问一答一两个字，显得“踏实”。但“先做”等于没回答，AI用极简来伪装深刻。 |
| “我们真的要搬？”“搬。” | **问答干脆体复刻** | 同上，连续第三次使用，已成模板。 |
| “今天是今天，明天是明天，每天都得重新算。先把规矩立住，路才能越走越宽。” | **格言缝合怪 + 强行升华** | 两句格言拼接，一句讲活在当下，一句讲长期主义，互相矛盾却都显得正确。AI最爱在结尾用这种句子拔高，完全不是人会说的话。 |

**总结：** 这段的核心AI味是“用格言代替生活”。人物没有算账、没有犹豫、没有脏话和废话，所有复杂选择都被压缩成一句漂亮话；配角要么捧哏要么使坏，没有中间状态；对话全是短平快的“问—金句答”，没有岔题、重复、结巴和真正的讨价还价。

### 二、改写版（约820字）

“姐，对面又降了。”阿强把抹布往水桶里一丢，水溅到脚面上，“我刚去买烟，他家门口黑板改了，五块变四块五了。”

冯丽正在择豆角，手没停：“他降他的呗。”

“降他的？咱中午少卖十几份了。”阿强蹲下来，“咱也降一块呗，降到六块，还比他贵一块五，但好歹近点。”

冯丽把一根有虫眼的豆角扔到一边：“降一块，一份少一块，一天八十份就少八十，一个月两千四没了。我这肉是今早五块九一斤进的，他那是冻货，能一样吗。我降了就得也进冻货，那味儿一变，老陈他们吃得出来。”

“那也不能干看着人被拉走啊。”

冯丽没吭声，把择好的豆角往盆里一倒：“先看两天。他敢一直四块五，我看他能撑多久。”

中午人确实少了。有两个以前常来的工人站在路口犹豫了一下，还是往对面去了。剩下的人里，老陈端着碗跟冯丽说：“老板娘，你家是贵点，但吃着不咋口渴。我上回吃对面那家，回来灌了一大杯水。”

冯丽笑了：“我盐放得少，味精也少放。”她给老陈又添了勺汤，“你慢吃。”

下午两点，一个戴安全帽的工头进来，张口就要三百份盒饭，明天中午要，送到工地。

阿强眼睛都亮了：“三百份？接啊姐，三百份得赚多少。”他转头就跟工头说，“能接能接。”

冯丽把他往后拽了一下，对工头说：“师傅，三百份我们真接不了。我们就两个人，两口灶，一顿最多出一百二三十份，三百份得从早上炒到中午，菜凉了也不好吃。你要不去问问对面？他们人多，量大。”

工头有点不高兴：“对面我问了，他说能接，但我看他那菜不行，才来问你的。”

“那要不这样，我给你做一百份，剩下的你再找一家分分，我保证十二点前给你送到。”冯丽说。

工头摇摇头：“一百份太少，算了。”走了。

阿强急了：“姐，一百份也是钱啊，咋往外推。”

“推啥，三百份得干到半夜，锅都得干废，做砸了几十号人吃不好，骂的是咱。”冯丽说，“咱这小店，接一百是帮忙，接三百是找死。”

晚上收摊，阿强说：“姐，听说对面把中午没卖完的菜，第二天加辣椒再卖。”

冯丽皱眉：“听谁说的，别乱传。”

“小卖部老板说的，看见他们把菜倒回锅里了。”

冯丽把碗摞起来：“那是他的事，咱把自己的菜弄新鲜就行，明天早点去挑排骨。”

过了一个月，房东来说下月涨两百，八百涨到一千。

阿强急了：“一千？他咋不去抢。”

冯丽问：“叔，九百行不，我们刚开没多久。”

房东摇头：“最少九百五，对面都愿意出一千二租，我没租给他算不错了。”说完走了。

阿强问：“姐，九百五也贵啊，咋办。”

冯丽把碗擦干放进柜子：“那就搬呗。下午我看了后面巷子一家要转，房租六百，就是偏点，得多走五分钟。偏就偏点，省三百多够买好几天肉了。明天你跟我去看看，行就定下来，这边做到月底。”
