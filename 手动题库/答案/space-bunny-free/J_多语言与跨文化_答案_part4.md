## 第 3 轮　本土化（重写，非翻译）

### 寄存

　　老陈每天下班走那条巷子，都要在"她那儿"停一下。

　　——

　　她那儿没有招牌。

　　门面是那种八十年代的老木门，玻璃上贴着一层发黄的白纸，纸是从里面糊的。门边挂一块黑塑料牌，油性笔写的：

**「寄存　人／物／名　当日取」**

　　老陈走了三年才注意到这个牌子。

　　——

　　柜台后面坐一个女的。三十来岁，穿黑棉袄，看着比老陈大。

　　她抬头看老陈，手里的笔停在半空。

　　"存点啥。"

　　"我妈的声儿。"

　　——

　　老陈妈走了六年了。

　　去年清明他在妈坟前坐了半天，回来以后忽然发现，他记得妈的声音，只剩两个：一部分是"吃饭了"，一部分是骂他。

　　别的全没了。

　　他不敢再想，越想越空。

　　——

　　女的给他一张表。

　　"名字。"

　　"陈立。"

　　女的写上了，撕下来，递给他。

　　一张纸条，右下角有个号：001。

　　——

　　第二天他又来了。

　　"存点啥。"

　　"我小学班主任的名字。"

　　——

　　第三天。"我第一回谈对象那张脸。"

　　第四天。"十七岁那年秋天，晒过的棉被味儿。"

　　第五天。"我妈压着嗓子说话那个样儿。"

　　女的抬头："跟昨天那个叠一块儿？"

　　"叠。"

　　——

　　第六天。"我爸在墙上撞那一下。"

　　——

　　第七天，老陈绕了远路。

　　他不想再一件一件往出拿了。

　　——

　　他还是去了。

　　他推门。女的在翻账本。

　　"存点啥。"

　　"我自己的名字。"

　　——

　　女的把笔放下了。

　　"名字不能存。"

　　"现在还在我身上。"

　　"那不是存。"她说，"那叫销号。"

　　——

　　老陈低头看手里那几张纸条。

　　001、002、003、004、005、006。

　　全是他的号。

　　别的什么都没有。

　　——

　　"这七天我用了自己七样。"

　　女的没说话。

　　"还剩啥。"

　　——

　　女的往旁边柜子上看了一眼。

　　柜子上摆着一排黑纸条，每一张都有号，号都不重样。

　　——

　　老陈走过去。女的没拦。

　　他一张一张翻。

　　001　女的声音

　　002　班主任的名

　　003　对象的脸

　　004　棉被的味儿

　　005　妈压着说话的样儿

　　006　爸撞墙那一下

　　——

　　底下还有两张。

　　007　陈立

　　008　（空的）

　　——

　　008 上什么都没有。

　　老陈不知道那是什么。

　　——

　　——

　　第二天早上，老陈照常出门。

　　走到巷口那个煎饼摊，摊主正把一屉子煎饼往炉子上扣，回头冲他喊了一嗓子：

　　"老陈，你也会吹哨啊。"

　　——

　　老陈愣了一下。

　　他把手放到嘴边。

　　他刚才，确实吹了一段。

　　他这辈子没吹过哨。

　　——

　　他往单位走，路过那家店。

　　门上那块黑塑料牌摘了。

　　换了一块新的，白底红字：

**「本日　营业」**

### 附　本土化处理说明

| 原作元素 | 本土化处理 |
|---|---|
| 无招牌的店、黑色塑料牌、"寄存 人／物／名 日取り" | 八十年代老木门、玻璃内糊发黄白纸、油性笔写的黑塑料牌 |
| 主角每天上班路过，半年后才发现 | 老陈走了三年才注意到这个牌子（拆掉了"半年"这个可疑的精确数） |
| 寄存"母亲的声音" | 清明上坟之后发现，"妈的声音"只剩下"吃饭了"和骂他两句 |
| 七个"エヌ氏"式符号名 | 只有一个真名：**陈立**。全篇其他人都无名 |
| 母亲三年前去世 | 六年（与"十八岁那年在棉被上"的时间差对齐） |
| 初恋的脸、洗毛线的味道、父亲的声音 | 第一回谈对象那张脸、晒过的棉被味、父亲在墙上撞那一下 |
| 女店员全程不说话，只在结尾说一句话 | 保留"说话极少"；但把她的核心台词从"寄存不是删除"改成了**"那叫销号"**——这是中国大陆日常生活里比"删除"更硬的一个词（销户、销号、备案撤销） |
| 柜台上一排黑纸条，编号各不相同 | 保留；这是全篇唯一"壮观"的镜头 |
| 007 是主角的名字，008 空白 | 保留，并把 008 处理成"什么也没写"，不做任何解释 |
| 翌日早晨，老人吹口哨，主角跟着吹 | 煎饼摊主喊他："你也会吹哨啊。"——他这一辈子没吹过哨 |
| 结尾贴出新牌子"本日　開店" | 摘掉黑塑料牌，换成白底红字"本日　营业"。**没有写这家店现在卖什么** |
| 教訓を明記しない（不写明教训） | 全篇没有一句议论。最后一句是一个纯动作：招牌被换了 |

**保留的核心创意**：一个人每天用自己身上的一样东西去换另一样；七件用完，他发现自己什么都没有留下；他想存下自己的名字，被告知那不叫存，那叫取消资格；第二天早晨他发现自己多了一项从来不会的技能，而这家店已经换了招牌。

**本土化之后我改掉的一处**：原作里"エヌ"这个符号人名，本身就是"被寄存的东西"（N 是一切的个数）。中文里没法用姓名的字形做这种双关，所以**陈立**这个名字不再承担装置功能；装置被移到了**"销号"这个词**上——中国的读者对"销号"有具体的、身体性的记忆（户口、社保、手机号、银行账户），这是日本读者对"エヌ氏"没有的。
