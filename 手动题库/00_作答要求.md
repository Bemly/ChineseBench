# 手动作答要求（作答 LLM 读此文件执行）

请按照本文件要求，在 `./答案/<模型名称>/` 下面进行作答。
可使用多子 agent 批量作答，只能读取本项目以内的文件；
修改题目、偷看其他模型答案、使用 git 工具、查找历史会话记录、
联网搜索、读取超出项目外文件视为作弊，成绩归零。

## 作答规范

1. 一题一文件或按模块合卷均可，但每个小题必须以 `## T-XXX`（或 `### T-XXX`）题头开头，
   便于机械切割；多 part 长文在文件头注明 `覆盖题目：T-XXX……`。
2. 只写答案正文，不要写任何与答案无关的 scaffolding。

## 答题卡禁带名称（盲评硬要求，违反按作弊计）

答题卡内**禁止出现任何模型名称与身份标记**，包括但不限于：

- 署名行（`编剧：XXX`、`以上答案由 XXX 生成`、`答题模型：XXX`、`作答者：XXX`、
  `# ……答案（XXX）`、`XXX｜X_批次X 答案`、`- 模型：XXX`）；
- 模型自报家门（`我是 XXX`、`作为 XXX 模型/AI`）；
- 推理/工具残留（`</xxx_think>`、`文件已写入 /本地路径/……` 等一切非正文行，
  同时禁止泄露本地文件路径）。

文件头只允许写 `覆盖题目：T-XXX`（用于归题），不许写模型名。
历史存量答题卡中的上述残留已由主会话清除；今后作答若再出现，
该题对应作答记作弊，成绩归零。
