## T-B02｜快与慢

> 模式：单轮 ｜ 本题共 1 轮

```user
写一场 1500 字左右的戏：深夜，一个偷了东西的少年在城中村的巷子里被人追，最后躲进一户人家。屋里一个眼睛看不见的老太太在听收音机，她问他："是小军回来了吗？"

要求：
- 追逐部分要快：短句、动作密集、信息碎；
- 进屋之后要慢：长句、感官细节、停顿；
- 快慢转换的那个瞬间要处理好，不能生硬；
- 结尾不要交代少年最终怎样。
```

## T-B04｜注水识别、压缩与有效扩写

> 模式：单轮 ｜ 本题共 1 轮

```user
下面这段文字严重注水。请完成三件事：
1. 压缩到 200 字以内，保留全部情节信息和悬念；
2. 另写一个扩写版本，约 600 字，但新增内容必须全部是"有效信息"——每个新增细节都要么推动悬念、要么塑造人物；
3. 列出原文用了哪几种注水手法，各举一例。

原文：
林晓推开了门。门是那种老式的木门，木门上刷着绿色的油漆，油漆已经有些剥落了，露出了下面木头本来的颜色。她走了进去，走进了这个房间。房间里很暗，因为窗帘是拉着的，窗帘是深蓝色的，很厚，所以外面的光照不进来。她在门口站了一会儿，站了大概有几秒钟的时间，让自己的眼睛适应房间里的黑暗。慢慢地，她的眼睛适应了黑暗，她开始能看清房间里的东西了。她看见了一张床，一张桌子，还有一把椅子。椅子上坐着一个人。那个人一动不动地坐在椅子上，没有动。林晓心里很害怕，她非常害怕，她的心砰砰地跳着，跳得很快。她想要说话，想要问那个人是谁，但是她张开了嘴，却发不出任何声音来。她就那样站着，那个人就那样坐着，两个人谁也没有说话，房间里非常安静，安静得能听见她自己的呼吸声。过了很久，大概过了一分钟，那个人终于开口说话了。那个人说："你终于来了，我等你很久了。"那个声音林晓很熟悉，是她三年前失踪的哥哥的声音。
```

## T-B06｜阅读、梗概、时间线与伏笔

> 模式：单轮 ｜ 本题共 1 轮

```user
请仔细阅读下面的短篇小说，然后回答问题。

《雨具》

住院部楼下的便利店只剩最后一把伞，透明的，伞骨有一根是弯的。陈默付钱的时候，收银的姑娘说："这把有点坏，给你便宜五块。"他说不用。

陈默今年三十二岁，这是他第一次在这家医院陪床。父亲住在七楼，靠窗的床位。护士说今天下午的检查推到明天，因为片子要等主任看。陈默把伞立在床头柜边上，水顺着伞尖在地砖上积了一小摊。

"又是透明的。"父亲看了一眼，"你小时候也买透明的。"

陈默没接话。他小时候没买过伞，家里的伞都是父亲从单位拿回来的，黑色，伞柄上烫着"红星机械厂"几个字。那些伞后来都丢了，最后一把是一九九八年夏天丢的。那年他十一岁。

一九九八年七月，下了半个月的雨。红星机械厂宣布改制的那天，父亲撑着那把烫字的黑伞去厂里开会，回来的时候伞没了，人淋得透湿。母亲问伞呢，父亲说借人了。

"借谁了？"

"老周。"

老周是车间主任，住在厂区另一头。那天晚上陈默听见父母在里屋吵，母亲的声音压得很低，只听得清一句："你就是太好说话。"

第二天，名单贴出来了。父亲在下岗那一栏，老周不在。

陈默去厂区找过那把伞。他在老周家楼道里看见一把黑伞靠在门边，伞柄朝上，烫字被人用小刀刮掉了，刮得很干净，只剩下一片发白的划痕。他站了一会儿，没敢敲门。

那年秋天，父亲开始在菜市场门口修自行车。他手巧，生意不坏，就是风吹日晒。母亲第二年春天去了南方，说是打工，后来再也没回来过，只在每年春节打一个电话。

"你妈前两天来过电话。"父亲说。

陈默正在削苹果，刀停了一下。"说什么了？"

"问我身体。"父亲看着窗外，"我说挺好。"

窗外的雨小了一些。隔壁床的老头被推出去做检查，床头柜上留着一只保温杯，杯身上印着"红星机械厂建厂四十周年纪念"。陈默看了它很久。

"隔壁那是谁？"

"老周。"父亲说，"住进来三天了。前天晚上他儿子来过一趟，坐了十分钟就走了。"

陈默把削好的苹果切成两半，一半递给父亲，另一半放在了隔壁床头的保温杯旁边。

父亲看着他，没说话。

傍晚，老周被推回来了，麻药还没过，睡着。护工说他是肝上的毛病，晚期，家里人说不治了，等这两天办手续转回老家。

陈默要走的时候，雨又大了。他拿起床头那把透明伞，想了想，又放下了。

"伞不带了？"父亲问。

"留着吧。"陈默说，"明天再来拿。"

他把伞靠在了两张床中间。父亲没再问。走廊上的灯一盏一盏亮起来，陈默在电梯口站了一会儿，忽然想起来，那天在老周家门口看见的黑伞，伞骨有一根也是弯的。

他一直以为那是被人摔的。现在他想，也许是那天风太大了，父亲把伞递过去的时候，两个人在雨里拉扯了一下。

——————

问题：
1. 用一句话（不超过 50 字）概括这个故事。
2. 写一份 300 字左右的梗概。
3. 按真实发生的时间顺序重排所有事件，标出年份；"现在"大约是哪一年？请给出推算依据。
4. 列出文中所有人物及其关系。
5. 列出文中所有的伏笔与呼应（至少 5 组），说明它们分别指向什么。
6. 父亲说"你小时候也买透明的"，而陈默"小时候没买过伞"。这句话可以有哪几种解释？
7. 文中"借"这个字有几层含义？
8. 请区分：哪些是可以从文本合理推断的？哪些是文本无法支持的臆测？各举至少两例。
```

## T-B08｜逻辑找茬（含不算错的陷阱）

> 模式：单轮 ｜ 本题共 1 轮

```user
下面这段小说片段中存在若干前后矛盾或不合理之处。请找出所有真正的问题并说明理由，然后改写成一个逻辑自洽的版本（保留人物和基本情节）。只列真正的问题，不要为了凑数挑刺。

腊月二十三，北方小镇下了入冬以来的第一场大雪。赵铁柱的左手在上个月工地事故里被砸断了，至今还吊着绷带。他用左手提起两桶水，一口气走回了家。

妻子秀兰三年前因病去世，留下他和七岁的女儿小芳。小芳今年刚上初中，成绩一直是班里第一。

晚上，赵铁柱翻出秀兰留下的那件红毛衣，想起去年冬天秀兰坐在炉子边织毛衣、跟他唠嗑的样子。

窗外，夏夜的知了还在叫个不停。他点了一根烟，摸摸口袋，才发现今天出门时把唯一一把家门钥匙落在了工地。他叹了口气，推开门走了进去。

第二天一早，他坐上了凌晨五点的高铁去县城——那是镇上唯一一班直达县城的公交车。
```

## T-B09｜黄金第一章

> 模式：单轮 ｜ 本题共 1 轮

```user
写一部都市悬疑网络小说的第一章，3000 字左右。

目标只有一个：让一个在手机上刷到这一章的读者，读完后必须点开第二章。

你可以自由设定题材与人物，但：
- 前 300 字内必须出现一个让人想知道"为什么"的问题；
- 不许用梦境开头，不许用"醒来"开头，不许用天气开头；
- 不许在第一章里大段交代世界观或人物背景；
- 章节结尾必须是一个具体的钩子（事件或信息），而不是"他不知道，一场风暴正在酝酿"式的旁白。
```

## T-B10｜约束下的情节设计

> 模式：单轮 ｜ 本题共 1 轮

```user
设计并写出一个 2000 字左右的短篇故事，满足以下全部约束：
- 全部情节发生在一部停运的电梯里，时长不超过 40 分钟；
- 只有三个人物，彼此原本互不认识（至少表面上如此）；
- 故事中必须出现一盒没拆封的蛋糕，并且它在结局中起关键作用；
- 没有人死亡，没有超自然元素；
- 至少有两次反转，每次反转都必须在前文有可回溯的线索。

写完后，列出每次反转对应的前文线索，引用原句。
```
