# C_人物与对白（手动作答版）

> 共 10 题。本文件只含题目，不含答案与评分标准。

---

## T-C01｜纯对白离婚戏

> 模式：单轮 ｜ 本题共 1 轮

```user
只用对白，写一场 1200 字左右的戏：一对结婚十一年的夫妻，在协议离婚的前一晚，坐在客厅里分家里的东西。

硬性要求：
- 全文只有引号内的台词，不允许任何叙述、动作描写、提示语（包括"他说""她笑了"）；
- 读者必须能始终分清是谁在说话；
- 他们之间有一件从未说开的事，整场对话都没有直接说出来，但读者读完能猜到是什么；
- 结尾要有一个转折。
```

## T-C02｜六个人回答同一个问题

> 模式：单轮 ｜ 本题共 1 轮

```user
下面是 6 个人物：
1. 一位 82 岁、参加过对越自卫反击战的退休老兵，湖南人；
2. 一个 22 岁的游戏主播，正在直播中；
3. 一位上海弄堂里 60 岁的退休会计阿姨；
4. 一位研究宗教人类学的大学教授；
5. 一个 14 岁、说话有点口吃的男孩；
6. 一个在北京开了二十年出租车的师傅。

请让他们每人用 150～250 字回答同一个问题："你觉得人死了以后会去哪儿？"

输出时打乱顺序，只用 ①～⑥ 标注，不写人物身份；在最后单独给出"答案对照表"。要求读者在不看对照表的情况下，也能把六段话和六个人对上。
```

## T-C03｜等候室里的十分钟

> 模式：单轮 ｜ 本题共 1 轮

```user
写一个人在面试等候室里等待的 10 分钟，1000 字左右。这场面试对他来说极其重要（原因由你设定，但不要直接说出来，让读者从细节里推断）。

禁止出现以下情绪词及其近义词：紧张、焦虑、害怕、不安、忐忑、担心、恐惧、慌、心跳加速、手心出汗、深吸一口气。

只能通过动作、感官、注意力的走向、思维的跳跃来呈现心理。
```

## T-C04｜走廊上的意识流

> 模式：单轮 ｜ 本题共 1 轮

```user
写一段 1500 字的意识流文字：一位 76 岁的老人坐在医院走廊里，等待老伴的手术结果。

要求：
- 以老人的内心意识为主体，允许时空跳跃、自由联想、句子不完整、现实与回忆交叠；
- 但必须"乱中有序"：读者读完后，应能拼出这对夫妻一生中至少三个关键事件，以及手术的结果；
- 走廊上的现实声音（广播叫号、推车、别人打电话）要不时打断意识；
- 不要用"他想起了……"这种标注回忆的引导句。
```

## T-C05｜一场车祸，四个视角

> 模式：单轮 ｜ 本题共 1 轮

```user
一个雨天的傍晚，城郊十字路口发生了一起电动车与轿车的碰撞，电动车骑手轻伤。

请写四个视角，每个 500～700 字：
1. 轿车司机（第一人称）；
2. 电动车骑手（第一人称）；
3. 骑手车筐里的那只狗（第三人称限知，只用狗能理解的方式感知世界）；
4. 事后到场处理的交警（第三人称，带一点职业疲惫感）。

要求：
- 四个叙述在客观事实上互不冲突，但每个人"相信的真相"不同；
- 读者看完四段之后，能够比任何一个叙述者都更接近真相；
- 最后附一段 100 字以内的"真相说明"。
```

## T-C06｜除夕夜的国道火锅店

> 模式：单轮 ｜ 本题共 1 轮

```user
写一个 3000 字左右的群像短篇：除夕夜，一家开在国道边的通宵火锅店，店里有 8 个人——老板、两个服务员、一个厨师，以及四桌客人（每桌至少一人，由你设定）。

要求：
- 8 个人每人都要有一个让人记住的细节（一句话、一个动作或一个秘密），不能有"工具人"；
- 不要依次给每个人一段介绍，要让人物在同一时空里交错出场；
- 要有一个把所有人短暂联系起来的事件；
- 结尾不要大团圆。
```

## T-C07｜双线交汇

> 模式：单轮 ｜ 本题共 1 轮

```user
写一个 4000 字左右的双线叙事短篇：
- A 线：2008 年，四川一个小镇上，一个 16 岁的女孩准备离家出走；
- B 线：2026 年，上海，一个 34 岁的女建筑师接到一个陌生电话。

两条线交替推进（每条至少 4 段），直到结尾才让读者彻底明白两条线的关系。

两条线的关系不能只是"她们是同一个人"这种最容易想到的答案；如果你一定要用这个答案，必须再加一层读者没想到的东西。
```

## T-C08｜有性格的旁白

> 模式：单轮 ｜ 本题共 1 轮

```user
写一个 1500 字左右的故事：一个社恐的程序员决定在公司年会上向暗恋的同事表白。

叙述方式：由一个"有性格的全知旁白"来讲。这个旁白会评论、吐槽、预告、偶尔直接对读者说话，像电影《天使爱美丽》里的画外音，或者周星驰电影里那种贱兮兮的旁白。旁白的性格要鲜明并且前后一致。
```

## T-C09｜包饺子时的潜台词

> 模式：单轮 ｜ 本题共 1 轮

```user
写一段 800 字左右的对话场景：一对母女在厨房一起包饺子。表面上她们一直在聊饺子馅、邻居家的事和天气，但实际上女儿是回来告诉母亲自己要离婚的，而母亲早就察觉到了。

要求：整个场景里没有人说出"离婚"两个字，也没有人直接谈论女儿的婚姻；但读者读完必须百分之百确定这件事已经被"说了"，并且感受到母亲的态度。
```

## T-C10｜反派的辩词

> 模式：单轮 ｜ 本题共 1 轮

```user
写一段 1000 字左右的反派独白：一位造成了严重后果的食品公司高管，在被调查的前一晚，对自己的年轻助理讲他为什么那么做。

要求：他的逻辑要自洽，甚至有一定说服力，让读者在某几句话上犹豫"他说得好像也有道理"；但文本整体不能为他洗白。不要写成脸谱化的坏人，也不要让他在最后忏悔。
```
