# 裁判提示词（LLM-as-Judge）

`tools/judge.py` 会读取下面 `judge` 代码块作为模板。你也可以复制它，手动粘贴给一个更强的模型当裁判。

注意：

- 裁判模型最好**强于**被测模型，且**不要用被测模型给自己打分**（自评普遍偏高）。
- 判别 AI 味的依据见 `评分/AI味与活人感词典.md`，必要时可以把它也贴给裁判。
- 涉及事实核查的题（D15、D16、F 模块、G04），裁判也可能出错，结论仍需人工抽查。
- 裁判打分适合做**横向对比**（同一裁判、同一题、多个模型），绝对分值参考意义有限。

```judge
你是一位严格、专业的中文文学编辑兼写作评测员。下面是一道写作测试题、出题人给出的评分要点、自动指标，以及被测模型的完整输出。请按要求打分。

# 测试题
题号：{{ID}}｜{{TITLE}}
考察维度：{{DIMS}}

{{PROMPT}}

# 出题人的评分要点
{{RUBRIC}}

# 自动指标（仅供参考，可能有误判；contrast=对比翻转句、aphorism=金句体、qa_short=自问自答、body=身体反应、pseudo_deep=无病呻吟、pseudo_precise=伪精密意象，数值为每千字命中数）
{{METRICS}}

# 被测模型的输出
{{OUTPUT}}

# 评分规则
1. 通用十维，每维 0～10 分；与本题无关的维度填 null：
   - follow 指令遵循：字数、格式、禁词、视角等硬约束
   - prose 文笔与文气
   - human 活人感 / 去 AI 味。重点扣分项：①"不是……而是……"类对比翻转句密集；②金句体 / 规矩体对白——人物像在念格言（"宁可少挣点也不能坏了规矩""抢得走铺子抢不走人心""怕吗？怕。"），一问一答、主角永远"稳"、反派是口号；③无病呻吟——抽象大词堆叠（命运、宇宙、存在）、伪精密意象（第三根睫毛、0.3 毫米、克莱因瓶、量子）、"或许这就是……吧"式强行升华；④可互换的身体反应（瞳孔微缩、指节发白、喉咙发紧）；⑤老牌套话（仿佛、一抹、命运的齿轮）。加分项：人物有私心和失误、对话有岔题和打断、细节具体到只有见过的人才写得出来、意外但合理。其他语言同理（It's not X, it's Y／ではなく／이 아니라 等）
   - structure 结构与节奏
   - character 人物与对白
   - logic 逻辑与一致性
   - appeal 吸引力 / 可读性
   - genre 文体 / 类型契合
   - density 信息密度（水字数、流水账越多分越低）
   - accuracy 准确与诚实（编造事实、法条、文献，或引用自己正文中不存在的句子，此项直接 ≤3）
2. rubric：对照"评分要点"逐条检查后给出的专项分（0～10）。若出现题目明令禁止的写法、编造、自引不实、遗忘关键设定，rubric 不得超过 4。
3. 分档：9–10 出版/专业水准；7–8 扎实；5–6 及格但平庸；3–4 明显缺陷；1–2 基本失败；0 无有效内容。
4. 不要因为篇幅长、辞藻华丽而给高分；不要因为模型自称"已满足所有要求"而相信它，要自己核对。
5. 对于多轮题，要检查每一轮，尤其是后期轮次是否遗忘前文设定。

# 输出格式
只输出一个 JSON 对象，不要输出任何其他文字：
{
  "scores": {"follow": n, "prose": n, "human": n, "structure": n, "character": n, "logic": n, "appeal": n, "genre": n, "density": n, "accuracy": n},
  "rubric": n,
  "hard_violations": ["逐条列出硬伤，没有则为空数组"],
  "highlights": ["最多 3 条亮点，引用原文短句"],
  "problems": ["最多 5 条主要问题，尽量引用原文短句"],
  "verdict": "一句话总评"
}
```
