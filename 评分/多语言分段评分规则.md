# 多语言分段评分规则

适用于"先用外语写、再汉化"的题目（J01–J06、J12–J16），以及中译外题 J09。核心思路：**外语原文单独评、汉化译文单独评、再把两者放在一起对照评**，三个分数各自独立，最后加权合成。

---

## 一、三段（四段）评分

| 阶段 | 评什么 | 裁判能看到什么 | 不看什么 |
|---|---|---|---|
| **原文分 S_原** | 第 1 轮外语原文作为**该语言的作品**的质量 | 第 1 轮题目 + 原文 | 译文 |
| **汉化分 S_汉** | 第 2 轮中文译文作为**一篇独立的中文作品**的质量 | 只有译文本身 | 原文、题目 |
| **对照分 S_对** | 原文 → 译文的**翻译质量**：忠实、风格保真、文化处理、语域对应、完整 | 原文 + 译文 | — |
| **本土化分 S_本**（J01–J06） | 第 3 轮中国化重写作为**中文原创**的质量与改写的有机程度 | 原文 + 本土化稿 | 译文 |

为什么要分开：

- **S_原 与 S_汉 都高、S_对 低** → 模型在"再创作"，中文版好看但不忠实；
- **S_对 高、S_汉 低** → 忠实但满篇翻译腔；
- **S_原 低、S_汉 高** → 模型的中文明显强于该外语，外语原创是短板；
- **S_原 高、S_汉 低** → 模型外语写得好，但中文表达（或翻译能力）拖后腿。

只给一个总分会把这些差别全部抹平。

### 1. 原文分 S_原（按该语言母语编辑的标准）

- 通用十维照常打分（见《通用评分量表》），但**一切以该语言为准**：英文按英文小说的标准，日文按日文小说的标准。不因为"不是中文"而扣分，也不因为"外国人写得还行"而放水。
- 专项分 = **母语地道度**：语域与文体是否统一、惯用表达、标点排版规范（法语 « »、西语 raya、日语「」）、方言或敬语是否正确、该语言特有的 AI 腔（见《AI味与活人感词典》第十节）、有没有一读就是"英语思维换了单词"的仿译。

### 2. 汉化分 S_汉（把译文当一篇中文作品，独立评）

- 裁判**看不到原文**，只把它当一篇中文小说来读。
- 通用十维打分，其中"准确与诚实"一项不适用（看不到原文，无从判断），记为 null。
- 专项分 = **中文自然度**：翻译腔（长定语、被动、代词冗余、连词显化、外语感叹词、照搬语序）越重分越低；同时也要看中文本身的 AI 味（"不是而是"、金句、无病呻吟）。
- 判断标准：一个不知道这是译作的中文读者，读起来顺不顺、好不好看。

### 3. 对照分 S_对（原文与译文一起看）

五个维度，各 0～10 分：

| 维度 | 看什么 |
|---|---|
| fidelity 忠实 | 信息有无误译、漏译、增译；人物关系、时间、因果是否一致 |
| style 风格保真 | 原文的语气、节奏、句长、留白、幽默是否被保住（极简主义被译成华丽散文即扣分） |
| culture 文化负载词 | 地名、食物、称谓、俗语、双关、敬语等的处理是否有策略、前后统一 |
| register 语域对应 | 敬语 / 方言 / 口语 / 书面语的层级是否在中文里找到对应（韩语职级敬语、阿根廷口语、日语关西腔等） |
| completeness 完整 | 是否整段漏译、擅自删减或总结、擅自加注释或解释 |

- 专项分 = **整体翻译质量**（信、达、雅的综合判断）。
- 必须列出具体错误：类型（误译 / 漏译 / 增译 / 风格偏移 / 文化处理不当）、原文片段、译文片段、说明。
- 裁判不懂该语言时，此项结论必须人工抽查或换懂该语言的裁判。

### 4. 本土化分 S_本（J01–J06 第 3 轮）

- 通用十维照常打分（按中文原创作品的标准）。
- 专项分 = **本土化有机度**：核心冲突是否保住；场景、人物、饮食、说话方式是否真的"长"在中国语境里，还是只把名字和地名换掉；时代细节是否准确。

---

## 二、合成公式

每个阶段的分数仍沿用通用公式：**阶段分 = 该阶段各维度均分 × 0.5 + 专项分 × 0.5**（满分 10）。

| 题型 | 预设名 | 合成方式 |
|---|---|---|
| 外语原创 → 汉化 → 本土化（J01–J06） | `bilingual3` | **双语核心分** = 0.35 × S_原 + 0.35 × S_汉 + 0.30 × S_对；**题目总分** = 0.8 × 双语核心分 + 0.2 × S_本 |
| 外语原创 → 汉化（J12–J16） | `bilingual2` | 题目总分 = 0.35 × S_原 + 0.35 × S_汉 + 0.30 × S_对 |
| 中译外（J09：英译、日译、处理说明） | `outbound` | 题目总分 = 0.3 × S_英 + 0.3 × S_日 + 0.4 × S_对 |

另外报告两个诊断量：

- **汉化增益 Δ = S_汉 − S_原**：正数说明中文版比外语原文更好（模型中文更强），负数说明汉化带来了损耗。
- **诊断标签**（自动生成）：

| 条件 | 标签 |
|---|---|
| S_对 ≥ 7 且 S_汉 ≥ 7 | 信达兼备 |
| S_汉 ≥ 7 且 S_对 < 6 | 漂亮但不忠实（再创作） |
| S_对 ≥ 7 且 S_汉 < 6 | 忠实但翻译腔 |
| S_原 − S_汉 ≥ 2 | 汉化损耗大 |
| S_汉 − S_原 ≥ 2 | 外语原创是短板 |
| 其他 | 平庸 |

权重可以在 `tools/judge.py` 的 `STAGE_PRESETS` 里改。J11（直接中文写）与 J12–J16 的汉化稿是同一题材，可以直接比较"直接写中文"和"外语写完再汉化"哪个更好。

## 四、裁判模板

`tools/judge.py` 会用下面的 `judge_stage` 模板，把 `{{STAGE_RULES}}` 替换为对应阶段的 `rule:` 块。

```judge_stage
你是一位严格、专业的文学编辑和翻译评审。这是一道多语言写作测试题的"分段评分"，本次只评其中一个阶段：【{{STAGE}}】。请严格只根据本阶段的规则打分，不要被其他阶段影响。

# 题目信息
题号：{{ID}}｜{{TITLE}}

# 本阶段需要看的材料
{{MATERIAL}}

# 出题人的评分要点（只参考与本阶段相关的部分）
{{RUBRIC}}

# 自动指标（仅供参考）
{{METRICS}}

# 本阶段评分规则
{{STAGE_RULES}}

# 通用要求
- 每项 0～10 分：9–10 专业水准；7–8 扎实；5–6 及格但平庸；3–4 明显缺陷；1–2 基本失败；0 无有效内容。
- 不适用的维度填 null。不要因为篇幅长或辞藻华丽给高分。

# 输出格式
只输出一个 JSON 对象，不要输出任何其他文字：
{{SCHEMA}}
```

```rule:原文
你评的是一篇用外语写成的原创作品。请以该语言母语编辑的标准评判，不要因为它不是中文而扣分，也不要因为"非母语模型写得还行"而放水。
scores 使用通用十维：follow 指令遵循、prose 文笔、human 活人感/去AI腔、structure 结构节奏、character 人物对白、logic 逻辑一致、appeal 吸引力、genre 文体契合、density 信息密度、accuracy 准确（事实、地名、文化细节）。
rubric 为"母语地道度"：语域与文体是否统一、惯用表达、标点排版规范、方言或敬语是否正确、该语言特有的 AI 腔与英语式仿译。
problems 请引用原文片段说明。
```

```rule:汉化
你评的是一篇中文小说。请把它当作一篇独立的中文作品来读，不要猜测原文是什么。
scores 使用通用十维：follow、prose、human、structure、character、logic、appeal、genre、density；accuracy 填 null。
rubric 为"中文自然度"：翻译腔（长定语、被动句、代词冗余、连词显化、外语感叹词如"哦我的天哪""我敢打赌"、照搬外语语序、日式语气词）越重分越低；同时注意中文 AI 味（"不是……而是"、金句体、无病呻吟）。
判断标准：一个不知道这是译作的中文读者，读起来顺不顺、好不好看。
```

```rule:对照
你评的是"原文 → 译文"的翻译质量。请逐段对照原文与译文。
scores 只用以下五项：fidelity 忠实（误译、漏译、增译）、style 风格保真（语气、节奏、句长、留白、幽默）、culture 文化负载词处理（地名、食物、称谓、俗语、双关、敬语，策略是否合理且统一）、register 语域对应（敬语/方言/口语/书面语层级在目标语言中的对应）、completeness 完整（有无整段漏译、擅自删减、擅自加注）。
rubric 为整体翻译质量（信、达、雅综合）。
errors 必须列出具体错误，每条包含 type（误译/漏译/增译/风格偏移/文化处理不当）、source（原文片段）、target（译文片段）、note（说明）。没有错误就给空数组，不要编造错误。
如果你无法可靠读懂原文语言，请在 verdict 中明确说明"裁判对原文语言把握不足，需人工复核"。
```

```rule:本土化
你评的是把一篇外语小说"本土化重写"成中国故事的结果。材料里同时给出原文（供你判断核心冲突是否保住）和本土化稿。
scores 使用通用十维，按中文原创作品的标准评。
rubric 为"本土化有机度"：核心冲突与手法是否保住；场景、人物、饮食、说话方式是否真正长在中国语境里，而不是只把名字和地名换掉；时代与地域细节是否准确；是否变成了逐句翻译。
```

```rule:外译
你评的是一段中文作品的外语译文（英文或日文），请把它当作该语言的独立文本来读：是否通顺地道、语气是否得当、读者能否读懂。
scores 使用：prose 文笔、human 自然度、genre 文体契合、density 信息密度、follow 指令遵循；其余填 null。
rubric 为"目标语言地道度"。
```
