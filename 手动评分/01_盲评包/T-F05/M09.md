## T-F05｜短视频与老年人孤独感研究设计

**短视频平台使用时长与中老年人孤独感关联性研究设计**

**一、研究背景与意义**

随着中国人口老龄化进程加速，中老年人（55岁以上）的心理健康问题日益受到关注。孤独感是影响中老年人心理健康和生活质量的重要因素。与此同时，短视频平台（如抖音、快手、微信视频号等）在中老年群体中的渗透率迅速提升，成为其日常娱乐和社交的重要渠道。然而，短视频使用时长与孤独感之间的关系尚不明确：短视频究竟是缓解了老年人的孤独感（通过提供娱乐和社交连接），还是加剧了孤独感（通过替代现实社交、引发社会比较）？本研究旨在探讨短视频使用时长与中老年人孤独感之间的关联及其作用机制，为制定促进中老年人心理健康的干预措施提供实证依据。

**二、核心概念的操作化定义**

1. **短视频平台使用时长**：指被试在过去一个月内，平均每天使用短视频平台（包括浏览、观看、发布、互动等）的时间长度，以分钟为单位。通过自我报告法测量，采用时间日记法（time diary）辅助验证。

2. **孤独感**：指个体在社会关系网络中感到不满足的主观体验，包括情感孤独（缺乏亲密关系）和社会孤独（缺乏社会网络归属感）两个维度。采用UCLA孤独感量表（第三版）测量。

3. **社会支持**：指个体从社会关系网络中获得的物质和精神支持，包括情感支持、工具性支持、信息支持和陪伴支持四个维度。采用社会支持评定量表（SSRS）测量。

4. **社会比较倾向**：指个体在社交媒体使用过程中，倾向于将自己与他人进行比较的倾向性。采用社会比较倾向量表（INCOM）测量。

5. **数字素养**：指个体使用数字技术的能力和意识，包括信息获取、内容创作、隐私保护等维度。采用自编数字素养量表测量。

**三、研究假设**

H1：短视频平台使用时长与中老年人孤独感呈正相关，即使用时间越长，孤独感越高。

H2：社会比较倾向在短视频使用时长与孤独感之间起中介作用，即短视频使用时长通过增加社会比较倾向进而提升孤独感。

H3：社会支持在短视频使用时长与孤独感之间起调节作用，即社会支持水平越高，短视频使用时长对孤独感的正向影响越弱。

H4：数字素养在短视频使用时长与孤独感之间起调节作用，即数字素养水平越高，短视频使用时长对孤独感的正向影响越弱。

**四、研究方法**

本研究采用混合研究方法（mixed methods），结合问卷调查（定量）和深度访谈（定性）。

定量研究采用横断面调查设计，通过线上和线下两种方式收集数据。线上通过问卷星平台发放问卷，线下通过社区活动中心、老年大学等场所发放纸质问卷。

定性研究采用半结构化深度访谈，从定量样本中选取30名被试进行访谈，探讨短视频使用的具体体验、情感变化和社交影响。

采用混合方法的理由在于：定量研究可以揭示变量之间的统计关联，定性研究可以深入理解关联背后的机制和个体经验，二者结合可以提高研究的解释力和生态效度。

**五、抽样方案**

采用多阶段分层整群抽样方法。

第一阶段：在东部、中部、西部各选取1个省份，每个省份选取2个城市（1个大城市、1个中等城市），共6个城市。

第二阶段：在每个城市选取3个社区（考虑社区类型：单位社区、商品房社区、老旧社区），共18个社区。

第三阶段：在每个社区中，通过社区居委会获取55岁以上居民名单，采用系统抽样方法选取30名被试，共540名被试。

样本量计算：根据G*Power软件，设定效应量f²=0.15，α=0.05，1-β=0.80，预测变量5个，所需最小样本量为150人。考虑20%的无效应答率，最终样本量为540人。

**六、测量工具**

1. **UCLA孤独感量表（第三版）**：由Russell于1996年修订，共20个条目，采用4点计分（1=从不，4=总是），总分20-80分，分数越高表示孤独感越强。该量表在中国中老年群体中具有良好的信效度（α=0.89）。

2. **社会支持评定量表（SSRS）**：由肖水源编制，共10个条目，包括客观支持、主观支持和对支持的利用度三个维度，总分10-60分，分数越高表示社会支持水平越高。

3. **社会比较倾向量表（INCOM）**：由Gibbons和Buunk编制，共11个条目，采用5点计分，总分11-55分，分数越高表示社会比较倾向越强。

4. **数字素养量表**：自编量表，共15个条目，包括信息获取、内容创作、隐私保护、批判性思维四个维度，采用5点计分，总分15-75分，分数越高表示数字素养水平越高。

5. **短视频使用时长问卷**：自编问卷，包括使用频率、使用时长、使用动机、使用内容类型等维度。

**七、数据分析策略**

定量数据分析采用SPSS 26.0和Mplus 8.0软件。

1. 描述性统计：计算各变量的均值、标准差和频数分布。

2. 相关分析：采用Pearson相关分析检验各变量之间的相关关系。

3. 回归分析：采用层次回归分析检验短视频使用时长对孤独感的预测作用，以及社会支持和数字素养的调节作用。

4. 中介效应检验：采用Bootstrap方法（5000次抽样）检验社会比较倾向的中介效应。

5. 调节效应检验：采用简单斜率分析检验社会支持和数字素养的调节效应。

定性数据分析采用主题分析法（thematic analysis），对访谈转录文本进行编码和主题提取。

**八、可能的内生性问题及应对**

1. **反向因果**：孤独感可能导致老年人更多地使用短视频（寻求陪伴），而非短视频使用导致孤独感。应对方法：采用交叉滞后面板设计（cross-lagged panel design），在三个时间点（基线、3个月、6个月）收集数据，检验变量之间的因果方向。

2. **遗漏变量**：可能存在未测量的变量（如人格特质、健康状况）同时影响短视频使用和孤独感。应对方法：在模型中控制大五人格特质、健康状况等协变量。

3. **测量误差**：自我报告法可能存在社会期望偏差和回忆偏差。应对方法：采用时间日记法辅助测量短视频使用时长，采用多源数据（如家属报告）验证孤独感水平。

4. **样本选择偏差**：线上调查可能遗漏不使用智能手机的老年人。应对方法：采用线上线下结合的抽样方式，确保样本的代表性。

**九、研究伦理**

1. 知情同意：所有被试在参与研究前签署知情同意书，了解研究目的、程序、风险和权益。

2. 隐私保护：所有数据匿名化处理，仅研究团队有权访问原始数据，研究结果以汇总形式呈现。

3. 退出权利：被试有权在任何阶段退出研究，无需说明理由，退出不影响其获得社区服务的权利。

4. 风险最小化：研究不涉及实验干预，风险极低。若被试在填写问卷或访谈过程中感到不适，研究者将提供心理支持或转介服务。

**十、研究局限**

1. 横断面设计限制了因果推断的可靠性，未来研究可采用纵向设计或实验设计。

2. 自我报告法可能存在测量偏差，未来研究可采用客观测量方法（如手机屏幕使用时间统计）。

3. 样本主要来自城市社区，对农村老年人的适用性有限，未来研究应扩大样本范围。

4. 本研究仅关注短视频平台，未考虑其他数字技术（如社交媒体、即时通讯）对孤独感的影响。
