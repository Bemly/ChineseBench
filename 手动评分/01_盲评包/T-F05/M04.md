### T-F05
**研究方案：短视频使用与中老年人孤独感的关联及其机制**

**一、研究背景与意义（简述）**

截至近年，我国 50 岁以上网民占比持续上升，中老年人成为短视频平台增长最快的用户群体之一（具体数据需引用中国互联网络信息中心《中国互联网络发展状况统计报告》最新版本）。与此同时，人口老龄化、家庭小型化、子女外出务工等因素，使中老年人的孤独感问题日益突出。短视频究竟是缓解孤独的"陪伴"，还是加剧孤独的"替代"，目前学界和公众舆论中存在不同看法。本研究试图检验两者之间的关联，并探究其作用机制，为理解数字技术对老年人心理健康的影响提供经验证据。

**二、核心概念的操作化**

| 概念 | 操作化定义 | 测量方式 |
|---|---|---|
| **短视频使用时长** | 受访者每天在抖音、快手、视频号等短视频平台上观看视频的时间（分钟） | ① 手机系统自带的"屏幕使用时间"数据（客观测量，经受访者授权截图）；② 自我报告作为补充 |
| **短视频使用方式** | 被动观看 vs 主动互动（评论、点赞、发布、与熟人分享） | 自编问卷：最近一周进行各类行为的频率（5 级量表） |
| **孤独感** | 个体主观感知到的社会关系在数量或质量上的不足 | UCLA 孤独感量表第三版（UCLA Loneliness Scale Version 3，Russell, 1996），20 个条目，4 级计分；考虑到老年人作答负担，可采用其 8 条目简版（ULS-8）进行稳健性检验 |
| **线下社会交往** | 受访者与家人、朋友、邻居面对面交往的频率 | 最近一个月面对面交往的次数及时长 |
| **代际联系** | 与不同住的子女的联系频率 | 最近一个月电话、视频通话、见面的次数 |

**三、研究假设**

H1：短视频使用时长与中老年人的孤独感显著相关。（不预设方向，分别检验 H1a 正相关与 H1b 负相关）

H2（中介假设）：短视频使用时长通过**挤占线下社会交往时间**，间接提高孤独感。即：使用时长 → 线下交往减少 → 孤独感上升。

H3（中介假设）：短视频的**主动互动式使用**（评论、分享给家人朋友）通过**增强社会联结感**降低孤独感；**被动观看式使用**则没有这一效应。

H4（调节假设）：**是否独居**调节短视频使用与孤独感的关系。对于独居老人，短视频使用与孤独感之间的关联更强（无论方向）。

H5（调节假设）：**代际联系频率**调节两者关系。与子女联系越少的中老年人，短视频使用对其孤独感的影响越显著。

**四、研究方法**

采用**混合研究方法**，以定量的追踪调查为主，辅以定性的半结构式访谈。

理由：
- 定量追踪调查可以检验变量之间的关联，并通过多时点数据在一定程度上处理因果方向问题；
- 定性访谈可以帮助理解短视频在中老年人日常生活中的具体角色和意义，解释定量结果，发现问卷未能涵盖的机制。

**（一）定量部分：两期追踪调查**

- 第一期（T1）：基线调查，测量所有变量；
- 第二期（T2）：6 个月后，再次测量所有变量；
- 采用交叉滞后面板模型（Cross-lagged Panel Model）检验短视频使用与孤独感之间的相互影响。

**（二）定性部分：半结构式访谈**

- 在定量样本中，根据短视频使用时长和孤独感得分，抽取四类典型个案（高使用—高孤独、高使用—低孤独、低使用—高孤独、低使用—低孤独），每类 5～8 人，共约 25 人；
- 访谈内容包括：使用短视频的起因、日常使用场景、观看内容、与家人朋友的互动、对短视频的感受等。

**五、抽样方案**

- **研究总体**：55 岁及以上、使用智能手机的城乡居民。
- **抽样方法**：多阶段分层抽样。
  - 第一阶段：按东、中、西部地区，各选取 2 个城市（共 6 个）；
  - 第二阶段：在每个城市，按城区和城郊/农村分层，各随机抽取 3 个社区/村（共 36 个）；
  - 第三阶段：在每个社区/村，根据居委会/村委会提供的居民名册，随机抽取 25 名符合条件的居民。
- **样本量**：计划样本 900 人。考虑到追踪调查的流失率（预计 15%～20%），第二期预计有效样本约 720～765 人。根据中等效应量、α=0.05、统计功效 0.8 的要求，并考虑分组调节分析的需要，这一样本量基本满足要求（需在正式实施前进行功效分析确认）。

**六、测量工具**

1. UCLA 孤独感量表第三版（20 条目）及简版 ULS-8；
2. 短视频使用时长：手机屏幕使用时间截图 + 自我报告；
3. 短视频使用方式问卷（自编，需进行预调查检验信度和效度）；
4. 社会交往与代际联系问卷（参考中国健康与养老追踪调查 CHARLS 的相关题项）；
5. 控制变量：年龄、性别、受教育程度、婚姻状况、居住安排、健康状况（自评健康、慢性病数量）、收入、城乡。
6. 抑郁症状：CES-D 简版（10 条目），作为控制变量或稳健性检验。

所有量表在正式调查前，需在 50 名中老年人中进行预调查，检验其理解程度和信度。

**七、数据分析策略**

1. **描述性统计**：样本基本特征、主要变量分布。
2. **相关分析与多元回归**：检验 H1，控制人口学变量和健康状况。
3. **中介效应检验**：使用 Bootstrap 方法（抽样 5000 次）检验 H2、H3 的中介效应。
4. **调节效应检验**：加入交互项，检验 H4、H5；对显著的调节效应进行简单斜率分析。
5. **交叉滞后面板模型**：利用两期数据，检验"短视频使用 → 孤独感"和"孤独感 → 短视频使用"两条路径的相对强度。
6. **个体固定效应模型**：利用两期数据，控制不随时间变化的个体特征（如性格），考察个体内部短视频使用变化与孤独感变化之间的关系。
7. **定性资料分析**：对访谈资料进行主题分析，与定量结果相互印证或补充。

**八、内生性问题及应对**

本研究面临的主要内生性问题包括：

1. **反向因果**：孤独的人可能更倾向于刷短视频来打发时间，而不是刷短视频导致孤独。
   - 应对：采用两期追踪数据和交叉滞后面板模型，比较两个方向的路径系数。

2. **遗漏变量**：性格内向、健康状况差、行动不便等因素，可能同时导致短视频使用增加和孤独感上升。
   - 应对：控制健康状况、行动能力等变量；使用个体固定效应模型控制不随时间变化的个体特征。

3. **测量误差**：老年人对使用时长的自我报告可能不准确。
   - 应对：以手机后台的屏幕使用时间数据为主要测量；对不愿或不能提供截图的受访者，进行敏感性分析。

4. **工具变量（备选）**：可考虑以"所在社区的 4G/5G 网络覆盖质量"或"子女是否帮助安装短视频 App"等作为工具变量，但其排他性约束需要谨慎论证，本研究仅作为稳健性检验的备选方案。

**九、研究伦理**

1. **知情同意**：以口头和书面两种方式向受访者说明研究目的、内容、风险和权利；对于阅读有困难的老年人，由调查员逐条朗读，确认理解后签字或按手印。
2. **隐私保护**：屏幕使用时间截图只记录使用时长，不涉及具体观看内容；所有数据匿名化处理，加密存储，仅研究团队成员可接触。
3. **自愿参与与退出**：受访者可以随时退出研究，不需要说明理由。
4. **心理风险应对**：孤独感量表和抑郁量表可能引发部分受访者的负面情绪。调查员需接受基本培训；对于孤独感或抑郁得分较高的受访者，在调查结束后提供当地社区心理服务资源和心理援助热线信息。
5. **伦理审查**：研究方案须通过所在单位伦理审查委员会的审查后方可实施。

**十、研究局限**

1. 两期追踪调查虽能在一定程度上处理因果方向问题，但仍不能完全排除内生性，结论应谨慎解读为"关联"而非严格的"因果"。
2. 样本仅包括使用智能手机的中老年人，不能推论到不使用智能手机的群体，而后者可能恰恰是孤独感更高的群体。
3. 短视频内容的异质性很大（娱乐、新闻、亲友动态、直播带货等），本研究对使用方式的区分较为粗略，未能对内容类型进行细致分析。
4. 孤独感量表在中国老年人群体中的适用性，虽有研究支持，但不同版本的测量结果可能存在差异，需在数据分析中进行稳健性检验。
5. 6 个月的追踪间隔较短，可能不足以观察到长期效应。
