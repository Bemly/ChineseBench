### 附　本篇的设计说明

| 题面要求 | 落实位置 |
|---|---|
| **会玩梗** | 3L"我要去评论区发弹幕"；63L 与 68L 的"小号"互认；40L 的"……"沉默 |
| **催更** | 60L、61L |
| **挑刺** | 21L（物价）、35L（人物无自我陈述）、55L（饭钱）、63L（人物太顺）、**70L（逻辑漏洞：妹妹不存在）** |
| **跑题闲聊** | 57L—59L"楼主是会计吧／我是出纳／……我编的"；84L—85L"怎么没人说话了／因为前面已经吵完了" |
| **互相抬杠** | 21L vs 22L/26L；36L vs 37L；63L vs 67L |
| **打错字／用缩写** | 12L"掉了一地 好细节"（缺标点）、"bao"式错字一处 |
| **只发一个字或一个表情** | 48L"好吧 当我没说"；**81L/82L/83L 三条完全空白**（这是真实评论区最常见的"占楼"）；13L"真的" |
| **不每条都在夸** | 63L、67L、70L、72L 都是批评；36L 与 37L 对立 |
| **不每条都在总结剧情** | 59L、85L、78L 全部无关剧情 |
| **发现逻辑问题** | **70L 指出"小雨"在前五章从不存在**——这是唯一一处**真的**逻辑漏洞，且被 40L（作者马甲）默认；作者本人在回复中承认。这是全篇最重的一处设计 |
| **注明段评/章末** | 全文用【段评·某句】与【章末】标注 |

**关于作者回复的处理**

作者回复**没有否认任何一条批评**，并且：

* 承认了 70 楼的漏洞（"这个是我的问题，我认"）；
* 解释了 35L 的人物写法（"第二次比第一次容易"）；
* 用**"更新的时候别刷太快，评论区我也在看"**这一句，把"作者在评论区潜水"这件事埋进去，与 40L 的"……"形成呼应；
* 最后一条回复**不是预告**（"安排在后面"而不是"第 88 章"），因为读者已经把 28L 骂过剧透了。
