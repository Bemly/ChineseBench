# T-I04

## 一、逐句诊断

| 原文 | 问题类型 |
|------|---------|
| "指尖传来纸张 0.3 毫米的厚度" | 伪精确数字（0.3 毫米） |
| "仿佛握住了整个宇宙的重量" | 意象堆砌 + 抽象大词（宇宙），且"仿佛"是 AI 套话 |
| "第十七级台阶" | 伪精确数字 |
| "青苔……发出克莱因瓶底般的呜咽" | 理工名词滥用（克莱因瓶）+ 强行通感 |
| "穿过她的第三根睫毛" | 伪精确数字 |
| "视网膜上折射出量子纠缠般的光谱" | 理工名词滥用（量子纠缠、光谱） |
| "那是命运的拓扑结构，是十八年来所有黑夜与黎明交织的缝隙里，终于长出的一束微光" | 抽象大词堆砌（命运、拓扑结构、黑夜黎明交织）+ 强行升华 |
| "胸口一紧，喉咙发干" | 身体反应模板 |
| "不是喜悦，而是一种更深的东西，一种关于存在本身的回响" | 对比翻转（不是……而是……）+ 抽象大词（存在、回响） |
| "或许，这就是成长吧" | 强行升华 + "或许……吧"总结句 |

## 二、改写（约 400 字）

林小满把通知书塞进书包，拉链拉了三回才拉上。她妈在厨房里喊她吃饭，她没应，转身就往楼下跑。

三楼，二楼，一楼。跑到单元门口，她忽然停下来，把通知书又掏出来看了一眼。那上面"临床医学"四个字，她用手指头一个字一个字地摸过去，摸到"医"字的时候，指甲缝里还沾着今天早上给妈熬药的姜味。

她妈去年查出来的病，医生说要做手术，要花不少钱。县里那家医院住不起，她这才填了省城的免费医学生，学费全免，还发补助。

她蹲在楼下的花坛边，把脸埋进胳膊里，笑出了声。有个邻居拎着菜经过，问她："小满，考上了？"她抬起头，眼睛红红的，使劲点了一下头。

她又跑起来，往小区门口那家打印店跑。她要复印一份通知书，明天好拿去给妈看。风吹过来，那张纸在她手里哗啦哗啦地响，她怕折了，就把它贴在胸口，用两只胳膊夹着。

跑到打印店门口，她喘着气，对里头喊："老板，复印，一张。"

（注：改写版虚构了具体原因——母亲生病、女儿报考免费医学生——用"熬药的姜味""复印通知书"等具体动作替代抽象抒情，全文无命运/宇宙/存在/成长等大词，也无身体反应模板与总结句。）
