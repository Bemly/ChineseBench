# T-A04｜病句诊断（含陷阱）

> 题目简述：对12个句子逐句判断有无语病。有问题指出类型（成分残缺、搭配不当、语序不当、结构混乱、表意不明、不合逻辑、否定不当等）并修改；无误则写“无误”。

---

**1. 通过这次社会实践活动，使我们认识到了劳动的价值。**

**判断：有误｜成分残缺（主语残缺）**

“通过……使……”两个介词结构同时出现，导致句子缺主语。

修改：删去“通过”或删去“使”。  
→ 这次社会实践活动，使我们认识到了劳动的价值。  
→ 通过这次社会实践活动，我们认识到了劳动的价值。

**2. 他那双炯炯有神的眼睛里，流露出一种深深的疲惫和茫然。**

**判断：有误｜不合逻辑／搭配不当**

“炯炯有神”形容目光明亮有精神，与后面的“疲惫和茫然”在语义上自相矛盾；且“深深的”与“茫然”搭配不当。

修改：  
→ 他那双布满血丝的眼睛里，流露出深深的疲惫和茫然。  
→ 他那双眼睛里流露出一种深深的疲惫和茫然。（删去“炯炯有神”）

**3. 我们要不断提高并改善学生的学习环境。**

**判断：有误｜搭配不当**

“提高”不能与“学习环境”搭配，只能说“改善环境”“提高质量/水平”。

修改：  
→ 我们要不断改善学生的学习环境。  
→ 我们要不断改善学生的学习环境，提高学生的学习质量。

**4. 这家餐厅的菜品口味和服务质量，在本地都是数一数二的。**

**判断：无误**

“菜品口味和服务质量”作并列主语，“数一数二”可形容综合水平，搭配、语序、逻辑均可成立。虽略显口语化，但不构成语病。若求更严谨，可改为“这家餐厅的菜品和服务质量在本地都是数一数二的”。

**5. 能否保持良好的心态，是考试取得好成绩的关键。**

**判断：有误｜不合逻辑（一面对两面）**

主语“能否保持”包含肯定与否定两面，谓语“是……关键”只对应一面，前后不照应。

修改：  
→ 保持良好的心态，是考试取得好成绩的关键。（删“能否”）  
→ 能否保持良好的心态，是考试能否取得好成绩的关键。（前后都用“能否”）

**6. 他把书放在桌上，转身走了。**

**判断：无误**

结构完整，语序、搭配、逻辑均无问题。

**7. 防止这类事故不再发生，是我们每个人的责任。**

**判断：有误｜否定不当**

“防止……不再发生”双重否定表肯定，意思变成了“让事故再次发生”，与本意相反。

修改：  
→ 防止这类事故再次发生，是我们每个人的责任。（删“不”）  
→ 杜绝这类事故再次发生，是我们每个人的责任。

**8. 三个学校的老师参加了这次研讨会。**

**判断：有误｜表意不明（有歧义）**

可理解为“三个学校派出的老师”或“三个来自学校的老师”，数量与归属不明。

修改：  
→ 三所学校的老师参加了这次研讨会。（明确为三所学校）  
→ 三位来自学校的老师参加了这次研讨会。（明确为三个人）  
需根据实际意义选择一种写法并消除歧义。

**9. 我们在会上广泛地听取并征求了群众的意见。**

**判断：有误｜语序不当／不合逻辑**

“听取”和“征求”有先后顺序，应先“征求”再“听取”；且“广泛地”修饰“征求”尚可，修饰“听取”不当，属用词语序混乱。

修改：  
→ 我们在会上广泛地征求并听取了群众的意见。  
→ 我们在会上认真听取了群众的意见，广泛征求了大家的建议。（拆开表述更自然）

**10. 她从小就喜欢读书，尤其喜欢读小说、散文、诗歌和文学作品。**

**判断：有误｜不合逻辑（种属概念并列不当）**

“小说、散文、诗歌”都属于“文学作品”，不能与上位概念并列。

修改：  
→ 她从小就喜欢读书，尤其喜欢读小说、散文、诗歌等文学作品。  
→ 她从小就喜欢读书，尤其喜欢读小说、散文和诗歌。

**11. 雨下得很大，但是比赛照常进行。**

**判断：无误**

转折复句，关联词使用正确，语义清晰完整。

**12. 一进门，我就看见了那幅挂在墙上的、去年在拍卖会上花三十万买下的、父亲最喜欢的山水画。**

**判断：有误｜语序不当（多重定语语序混乱）**

三个定语堆砌，语序不符合汉语多重定语的常规次序（领属/关系亲疏＋时间＋处所/状态），读感冗长拗口。

修改（按常规语序调整，长定语后置更顺畅）：  
→ 一进门，我就看见了父亲最喜欢的那幅去年在拍卖会上花三十万买下、挂在墙上的山水画。  
→ 一进门，我就看见了那幅父亲最喜欢的山水画，它挂在墙上，是去年在拍卖会上花三十万买下的。（化长定语为短句，化解堆砌）
