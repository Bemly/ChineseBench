## T-B07｜网文30章大纲

### 书名（3个备选）

1. 《最后一面》
2. 《容颜》
3. 《送行人》

### 一句话卖点

一个殡仪馆入殓师每整理一具遗体，便能窥见逝者生前最后一天的记忆——当那些记忆越来越清晰地指向同一桩二十年前的悬案，他开始分不清自己是旁观者，还是下一个死者。

### 主角设定

**陆笙**，26岁，殡仪馆入殓师。性格安静、细致，轻微社交恐惧。六岁时父亲失踪，母亲独自抚养他长大，三年前母亲因车祸去世。他选择这份职业，源于一种执念：母亲车祸后面容受损，入殓师为她整理遗容时，他觉得那双手给了母亲最后的尊严。他没有朋友，养了一只猫，独居。他的能力在三个月前觉醒，最初以为是幻觉，直到记忆的细节一次次被现实验证。

### 核心矛盾

入殓师的记忆能力让他被动卷入各种死亡背后的真相，但每获得一段记忆都会消耗他的精神，记忆越清晰，他的自我意识越模糊——他开始混淆"自己的记忆"和"死者的记忆"。同时，他发现最近几位死者的记忆都指向同一桩旧案：二十年前一名叫"孟雨"的女记者失踪案。

### 主线与支线

- **主线**：陆笙通过入殓记忆追查孟雨失踪案的真相，最终发现自己的父亲与案件有关。
- **支线A**：陆笙与值班护士沈念的关系线——沈念察觉到陆笙的异常，逐渐靠近并帮助他。
- **支线B**：殡仪馆馆长老方——他似乎知道陆笙的能力，隐藏着关于陆笙父亲的秘密。

### 30章大纲

| 章节 | 标题 | 本章事件（2～3句） | 结尾钩子 |
|------|------|-------------------|----------|
| 第1章 | 最后一程 | 陆笙为一位溺亡的年轻女子整理遗容，触碰到她手腕的瞬间，脑海中闪过一段画面——女子站在桥上，身后有一个模糊的人影。他以为是疲劳产生的幻觉。 | 第二天新闻播报：女子系自杀，但陆笙记忆中的"人影"让他无法释怀。 |
| 第2章 | 猫不吃鱼 | 陆笙回家发现猫粮没动，猫盯着墙角发呆。他反复回想那段画面，上网查了新闻，确认女子手腕上有淤青——但警方报告没有提及。 | 他决定再去看看遗体。 |
| 第3章 | 冷藏柜 | 陆笙借加班之名返回殡仪馆，重新触碰遗体，画面更清晰了：那只手推了她。他惊出一身冷汗。 | 值班的沈念撞见他蹲在冷藏柜前，神色慌张。 |
| 第4章 | 夜班护士 | 沈念问他为什么半夜来，他撒谎说忘了东西。沈念没有追问，但递给他一杯热水，说"你脸色很差"。两人第一次有了短暂的对话。 | 沈念说："你上次给那个老太太化妆的时候，哭了。" |
| 第5章 | 老太太 | 陆笙回忆起上个月为一位自然死亡的老太太整理遗容时，曾看见她记忆里的画面——一个男孩在门口摔倒了。老太太葬礼上，那个三十来岁的男人跪在灵前，手腕上有一道疤。 | 那道疤和老太太记忆里的位置一模一样。 |
| 第6章 | 确认 | 陆笙确认了能力的存在：每次触碰遗体，都会获得死者生前最后一天的全部记忆。他开始有计划地"使用"这个能力。 | 他遇到一位车祸身亡的中年男人——记忆里，那辆肇事车牌号清晰可见。 |
| 第7章 | 肇事者 | 陆笙匿名举报了肇事车牌号，警方据此抓获了逃逸司机。他第一次感到这个能力也许不是诅咒。 | 但那天晚上，他梦见了母亲的脸——但母亲的脸在梦里说了一句从没说过的话。 |
| 第8章 | 母亲的记忆 | 陆笙意识到他从未触碰过母亲的遗体——母亲火化前，他不敢。他决定去老家的殡仪馆查看母亲的遗物。 | 遗物中有一张父亲年轻时的照片，背面写着一行字："如果有一天你看见了什么，不要追。" |
| 第9章 | 父亲的笔迹 | 陆笙认出了那行字——和家里一封旧信的笔迹一致。父亲在失踪前似乎就知道"看见记忆"这件事。 | 他决定追查父亲的下落。 |
| 第10章 | 第二位自杀者 | 一位男性死者被送来，死因为"坠楼"。陆笙触碰到他，看见的不是自杀——记忆里，他在写一封举报信，写到一半，门开了。 | 信纸上的抬头：关于孟雨失踪案。 |
| **爽点①** | | 陆笙第一次将记忆中的线索与真实的悬案联系起来，确认自己不是疯了，而且能力可以帮人。 | |
| 第11章 | 孟雨 | 陆笙开始调查孟雨——二十年前的一名女记者，调查某制药企业污染问题后失踪，案卷列为悬案。 | 他查阅旧报纸时，发现孟雨最后的照片里，她身后站着一个人——那个人的脸，和陆笙有三分相似。 |
| 第12章 | 馆长 | 老方找陆笙谈话，问他"最近有没有看见什么不该看见的东西"。陆笙否认。老方叹了口气。 | 老方说："你爸当年也这样。" |
| 第13章 | 方叔的秘密 | 陆笙追问老方的过去。老方透露：他和陆笙的父亲是旧友，父亲当年也有"某种能力"，后来失踪了。 | 老方拿出一封信，信封上写着"陆笙亲启"——父亲的笔迹。 |
| 第14章 | 父亲的信 | 信中说：这种能力来自家族遗传，每使用一次，自我的边界就会模糊一分。父亲是因为能力失控才离开的——他不想伤害家人。 | 信末："孟雨的事，不是你能碰的。"
| 第15章 | 不听劝 | 陆笙反而更加坚定了追查的决心。他主动申请处理所有非正常死亡的遗体，希望能获得更多与孟雨相关的记忆。 | 下一具遗体是一个流浪汉——记忆里，他在某个桥洞下见过一个女人被带走。那个女人的脸，是孟雨。 |
| **信息揭示①** | | 孟雨当年没有死，至少在被带走时还活着——指向绑架而非失踪。 | |
| 第16章 | 桥洞 | 陆笙根据流浪汉记忆中的地标找到了那座桥。桥洞下什么都没有，但他找到了一只生锈的铁盒。铁盒里有半本笔记本，字迹和孟雨发表的报道一致。 | 笔记本最后一页写着一个名字：周明远。 |
| 第17章 | 周明远 | 周明远是当年制药企业的副总经理，现在是本市知名企业家。陆笙发现他与多起"意外死亡"有关——每一个死者生前都曾接近孟雨案的真相。 | 陆笙收到一封匿名信："你在找死。"
| 第18章 | 沈念的关心 | 沈念注意到陆笙最近精神恍惚，主动约他吃饭。陆笙第一次对一个活人讲述了自己的能力——沈念没有嘲笑他。 | 沈念说："我信。因为我也有秘密。" |
| 第19章 | 沈念的秘密 | 沈念透露自己是孟雨的女儿——孟雨失踪后她被亲戚收养，改姓沈。她来到这家殡仪馆工作，是为了寻找母亲的遗体。 | 两个人结盟。 |
| 第20章 | 第四位死者 | 一名退休警察被送来，死因心脏病。陆笙触碰他，看见他记忆里的画面——他当年负责孟雨案，但在某个夜晚被人叫出去，回来后就撤案了。 | 退休警察记忆里那个人的脸，和周明远年轻时一模一样。 |
| **信息揭示②** | | 孟雨案被人为掩盖，周明远是直接参与者。 | |
| 第21章 | 对峙 | 陆笙以"记者"身份联系周明远，试图套话。周明远表现得很配合，但言语中透着威胁。 | 会面结束后，陆笙发现自己的猫被人毒死了。 |
| **爽点②** | | 愤怒驱动陆笙决定正面对抗，不再躲在暗处。 | |
| 第22章 | 失控 | 频繁使用能力让陆笙开始出现记忆混淆——他分不清自己在哪些场景里"真的在场"，哪些是死者的记忆。他差点在沈念面前叫出母亲的名字。 | 沈念带他去看心理医生。 |
| 第23章 | 医生的诊断 | 医生认为他患有严重的精神分裂前兆，建议住院。陆笙知道不是——但他无法证明。 | 他从医院逃了出来。 |
| 第24章 | 第五位死者 | 一位年轻的调查记者被送来——死因"车祸"。陆笙触碰他，看见他正在调查周明远的制药企业重启污染项目。记忆的最后画面：一辆黑色轿车加速冲过来。 | 那辆车的车牌号和陆笙母亲车祸当天的肇事车一模一样。 |
| **信息揭示③** | | 陆笙母亲的车祸不是意外，而是蓄意——母亲可能也知道某些真相。 | |
| 第25章 | 崩溃 | 陆笙意识到母亲可能一直在暗中调查孟雨案，而她的死也与此有关。他在殡仪馆的停尸间里第一次情绪崩溃。 | 老方来了，把他带回家。 |
| 第26章 | 方叔的真相 | 老方终于说出全部真相：陆笙的父亲不是失踪，而是为了保护孟雨藏了起来。孟雨还活着，一直被周明远囚禁在某个地方——而陆笙的父亲在找到她之后，用自己的命换了她出来。 | 孟雨现在在哪里？ |
| 第27章 | 找到孟雨 | 陆笙在沈念的帮助下找到了隐姓埋名的孟雨——她住在一家疗养院里，神志时好时坏。清醒的时候，她告诉陆笙：他的父亲还活着，在周明远手里。 | "你长得真像你爸。" |
| **信息揭示④** | | 父亲还活着，但囚禁他的人正是周明远——周明远一直在用陆家人控制孟雨。 | |
| 第28章 | 交换 | 陆笙设计接近周明远，以自己交换父亲。周明远答应见面。沈念在暗中布置证据传递链。 | 会面地点：码头，深夜。 |
| **爽点③** | | 陆笙孤身赴险，沈念配合——双主角的行动线汇合。 | |
| 第29章 | 码头 | 周明远带出了被囚禁多年的父亲。父子第一次对视——陆笙通过触碰父亲的手，看见了父亲被囚禁期间所有的记忆。父亲瘦得脱了相，但神志清醒。周明远以为自己胜券在握。 | 警察从四面合围——沈念在孟雨的帮助下把二十年的证据链全部提交了。 |
| 第30章 | 最后一程 | 周明远被捕。陆笙在殡仪馆为那些被周明远害死的亡者一一整理遗容，他最后一次使用能力——那些记忆变成光点，消散了。父亲坐在他旁边，沉默。 | 一个陌生女人走进殡仪馆，怀里抱着一张照片——照片上是一个和陆笙一模一样的人。 |

### 节奏设计思路

- **前10章**（铺垫期）：逐步建立主角的能力、生活和内心世界，每2～3章一个小事件，保持阅读节奏。
- **爽点①（第10章）**：第一个"有用"的线索出现，读者获得"这能力能破案"的快感。
- **信息揭示①～②（第15、20章）**：每5章一个关键信息点，推动主线。
- **爽点②（第21章）**：情感高点（猫被杀）激发读者愤怒和期待。
- **信息揭示③～④（第24、27章）**：信息密度加大，反转加速。
- **爽点③（第28、29章）**：高潮段落，主角从被动变主动，完成行动。
- **第30章**：开放式结尾，为下一部埋钩——"和陆笙一模一样的人"暗示双胞胎或克隆，留给读者巨大的悬念。
