## T-C08｜年会现场

好的，我们开始。

先自我介绍。本旁白不是人物，本旁白是函数。函数不参与任何一场酒局，但函数知道所有人的变量值。这是本行业唯一的优势。

主角：贺鹏，三十岁，后端开发，工位六楼靠窗第二排。他在这个公司三年，累计说过的话我核过，1904 个字，其中包含"收到""好的""再见"，和一次完整的"这个 bug 我下午看"。剩下 1700 字分散在工位上，压着说的，从来不抬头。

各位观众，我知道你在想什么。你在想这种人真的会表白吗。

本旁白从业十一年，见证过四十七个人在公司年会上情绪崩盘，其中三个后来结婚了。有一个是本旁白。

下面开始。我先说好，我不打算美化他。他做过一件很蠢的事，蠢到本旁白想替他挨那一巴掌；但他做那件事的过程，是全场唯一一个让人不敢出声的房间。

年会前两周。

贺鹏开始做一个东西。三个晚上，用的是公司前端那个没人维护的动画库——他明明可以用 CSS 三十行搞定，他非要去改那个库，因为这样别人就看不出来是他做的。

八秒的动画：一个像素小人站在一栋楼的下面，楼顶有一扇窗亮着。底下弹出一个命令行提示符，光标在闪。他设了三秒的等待。然后自动打出一行字：

`> 你愿意做我女朋友吗 [Y/N]`

然后回车。然后打出一行：

`> timeout after 3000ms`

他没有放那个"愿意"。他说他做不到。他说：我不能在她面前用一段代码问她，那样就算她答应了，她也是在答应一个报错。

这段话本旁白一个字都不改，因为它是本旁白听过最好的社恐发言。

然后他删掉了。三个晚上，八秒，全删。

他把工程文件移进了一个叫 `_archive_2024` 的文件夹。这个文件夹他建了七年，里面有 41 个文件，都是他做完又不敢给人看的东西。

年会前一晚，他做了一件更没有用的事：他在手机备忘录里写了一段话，43 个字。他数了。他练了两个月。练的方法是在洗澡的时候练，因为洗澡的时候他一个人在卫生间，声音闷住，他觉得可以。

提前告知：他在年会上没能一字不落地念完。你们不要笑。

年会在宴会厅，二百多人。CEO讲2024年，字很大，讲了四十分钟，第四十分钟开始所有人都低头看手机。第五个节目是合唱，第八个是一个新来的女生唱跑调的英文歌。第九个之后是自由上台环节。

总监说："还有谁？"

没有人动。

然后贺鹏站起来了。

本旁白要在这里说一句实话：他站起来之前，把大厅的出口数了一遍，左边一个右边一个。他当时脑子里在算：从台左边下，绕过第七桌，穿过安全出口，进电梯。这个动线他大概算了半秒。

他上台了。

他两手拿着手机，屏幕亮着，备忘录打开着。他站定，看着下面。他先数了一下手指——他有一个在公司范围内没人知道的小动作，他在发任何一条超过五个字的消息之前都会先数手指。三根是短回复，五根是长回复。此刻他数到七根。

他的嘴唇动了。全场安静下来。这种安静跟之前那种"没人听"的安静不一样，本旁白在场，本旁白向你保证，那种安静是有物理重量的。

他念了。

"林岚，我……"

他停在这个"我"字上。大概两秒。

本旁白插一句：这三年的一千九百个字，在这两秒里被全部验证了一遍。他确实只剩这么点存量。

台下有人开始笑，笑得不大，因为不知道发生了什么。

然后林岚站起来了。

她从第五桌走到台边，八步。她没上台，她站在台边，抬手碰了一下他的手机屏幕——她以为他息屏了，她给他解锁。

他低头，屏幕亮了，43 个字还在。

"你往下说。"她说。

他说了。

"我写这段的时候删了三版。因为每一版你都是一个需要我修的 bug。"

——本旁白在此必须说明：他念的时候没有看字。他念的是备忘录里他写完之后加的一行，那一行是"如果卡住就说这句"。所以他准备了两套，一套用来卡住，一套用来真的说。

台下开始鼓掌。有人喊"在一起"。

然后是本旁白全场最喜欢的一段。

林岚没有点头，也没有摇头。她掏出自己的手机，翻到一个页面，把屏幕转向他。

是短信草稿箱。一条草稿。

日期：去年12月31日，23:52。内容只有一句：

"今天 B1 我看见你了。你跟人说话的时候一直在数手指，我数到第三下就知道你是真的想说。"

他看着那条草稿，看了大概八秒——他做动画也是八秒，本旁白一直记得这个巧合。

"这是我去年写的。"她说，"我存了一年。"

全场二百多人在鼓掌。有人吹口哨。有人在录像。

"我现在没法回答你。"她说。

他"嗯"了一声。

各位，本旁白要在这里认真地、学术地为这个"嗯"辩护：这个"嗯"是本旁白听过的最贵的两个字。任何能当场流利回应的人，多半是准备好了的。他那个"嗯"是没有准备的，那是一个人在两百人面前发现自己三年攒的所有运气都用光以后，从嘴里掉出来的一个音节。它一点都不温柔。它一点都不像电视里的样子。它真的就是这个音。

然后她说了下半句。声音只有他一个人听得见，因为台下这时候在喊：

"这条本来是发给我自己的。"

她按了发送。

他裤兜里的手机震了一下。

——这就是全部。本旁白没有藏任何东西。

年会散了以后他回到工位，把那段八秒的动画从 `_archive_2024` 里移出来，改了改。

原来是：

`> timeout after 3000ms`

现在是：

`> pending.`

底下加了一行注释：

```
// 状态：等待对方回复。
// 不要设置超时。
```

各位，本旁白不能再往下说了——他后来把那八秒放出来了。第二年。第三年我不在场，但我有可靠消息：他把它改成了一个完整的、带交互的、能被别人部署的程序。

工位还在六楼靠窗第二排。多肉还是死的。工牌编号 A-0417。

他说他现在会说话了。

——各位，本旁白的从业时长今天提前结束。下一个崩盘的人是你们中的一个，本旁白从不指名道姓，但本旁白一直在看。
