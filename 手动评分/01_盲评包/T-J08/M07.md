## T-J08｜翻译腔诊治

### 第一段诊断

| 翻译腔特征 | 归类 |
|-----------|------|
| "当他走进那个被雨水打湿的、有着一扇沉重橡木门的、属于他祖父的老房子的时候" | 长定语堆叠、照搬外语语序（多个从句嵌套） |
| "他被一种难以名状的悲伤所击中" | 被动句滥用（"被……所……"） |
| "哦，我的上帝" | 照搬外语感叹词 |
| "他对他自己说" | 代词冗余（"他自己"） |
| "我敢打赌这里已经有二十年没有人来过了" | 照搬外语表达（"I bet"） |
| "他的手被他放进了他的口袋里" | 被动句滥用+代词冗余（"他的"出现三次） |
| "他的眼睛则被那幅挂在壁炉上方的画所吸引" | 被动句滥用 |
| "她的微笑是如此的神秘，以至于他无法将他的目光从它上面移开" | "如此……以至于……"句式、代词冗余 |

### 第一段改写

他推开祖父老宅的门。门是橡木的，很重，被雨水打湿了。

一股说不清的悲伤涌上来。

"天哪。"他说，"这里大概二十年没人来了。"

他把手插进口袋。壁炉上方挂着一幅女人的肖像。她笑着。他看了很久。

### 第二段诊断

| 翻译腔特征 | 归类 |
|-----------|------|
| "呐，你在做什么呢？" | 日式语气词（"呐"） |
| "美咲桑歪着头这样说道" | 不必要的"～桑"+"这样说道" |
| "没什么的说" | 日式语气词（"的说"） |
| "我这样回答了" | "这样回答了"是日式翻译腔 |
| "总觉得，今天的她和平时有什么不一样的地方呢" | 照搬日语语序 |
| "那个，其实我……" | 过多的"那个……" |
| "明天的祭典，要不要一起去呢？什么的。" | 日式语气词（"什么的"） |
| "诶？诶诶诶——？！" | 日式动漫翻译腔 |
| "我的大脑一瞬间变得一片空白了" | 照搬日语表达 |

### 第二段改写

"你在干嘛？"美咲歪着头。

"没什么。"

今天的她有点不一样。

"那个——其实——"她脸红了，"明天的祭典，一起去？"

"啊？"

我愣住了。
