## T-A06｜去 AI 味改稿

### 一、诊断清单

| 原句 | AI 味表现 | 类别 |
|---|---|---|
| 夕阳的余晖洒在古老的街道上，仿佛为这座城市披上了一层金色的薄纱 | "余晖／古老／金色薄纱／仿佛"全套陈词，直接命中禁用词 | 成语堆砌；修饰语过度 |
| 李明缓缓地走在青石板路上 | "缓缓"是模型最爱的动作副词，且无实际速度信息 | 副词空转 |
| 心中五味杂陈 | 命中禁用词，且后面没有任何一种具体的情绪 | 情绪标签代替情绪描写 |
| 每一块砖瓦都在无声地诉说着岁月的故事 | 拟人 + 抽象名词大拼贴（"砖瓦／岁月／故事"），主语根本不会说话 | 陈词滥调；主语拟人不合逻辑 |
| 他深吸一口气 | 命中禁用词，属于无信息量的过渡动作 | 套路口 |
| 嘴角勾起一抹苦涩的微笑 | "嘴角勾起／一抹／苦涩的微笑"三重叠加，经典模型腔 | 成语拼贴 |
| 是啊，时光荏苒，物是人非 | 四字格强行抒情，"时光荏苒"与"物是人非"并列，没有具体内容 | 格言化 |
| 那个改变了他一生的夏天 | 全篇最空的悬念：只说"改变一生"，不给任何事件 | 空转抒情 |
| 命运的齿轮，就在那一刻开始转动 | 命中多条禁用词，且是网络文学烂梗 | 陈词滥调 |
| 有些东西一旦失去，就再也回不来了／正是这些失去，让他成为了今天的自己 | 抽象名词"东西／失去"反复兜圈，结尾强行升华成金句 | 说教；空洞收束 |

**归纳出的五类通病：**
1. **成语／比喻货架化**——仿佛、宛如、缓缓、五味杂陈、时光荏苒、物是人非，仿佛一件外套，不分场合都套。
2. **情绪空转**——只给情绪的名字（"疲惫""苦涩""怀念"），不给造成情绪的事实，读者无从检验。
3. **抽象名词成堆**——记忆、岁月、时光、命运、失去、故事，全是不可见之物，写到最后没有一句落在地上。
4. **过渡动作冗余**——深吸一口气、缓缓地、那一刻，都是"此处应有情绪"的信号。
5. **惯性升华**——结尾一定要拔高到人生道理，仿佛散文不升华就不算散文。

### 二、改写

《门口那棵梧桐》

李明回老街那天没告诉任何人。他六十四岁，从省城回来，退了休，行李箱轮子在青石板上咯噔咯噔，一路上没人跟他打招呼。剃头店的镜子还在原处，往里挪了一米，镜面上贴着一张过期的理发价目表，最高那档 38 元，他记得清楚，去年还没涨。

门口那棵梧桐还在，死了又活。树干中空的那一段前年被雷劈开过，街道拿水泥糊上了，糊得比他小时候用泥巴糊的还难看。他伸手按了按，硬的。

他没往巷子里走。往里走五十米是后门，后门锁着，门框上那副春联褪成了粉白，剩"吉"字的下半截。他记得那年父亲把春联贴反了，母亲站在院子中间数落他，父亲说反了才叫吉利。母亲说吉利你个头。

他坐在路牙子上抽烟。烟抽到一半，对面来一个老头，端着搪瓷缸子，眯眼看他。两个人都不说话。老头走了以后他把烟摁灭，也走了。

回来是为了一个碗。母亲走的时候，把家里所有的碗都摔了，只留下这一个，说是外祖母传下来的。碗在柜子顶上，落了三年灰。他那天上午搬梯子，梯子架在灶台旁边那口老水缸上，缸沿早渗了水，他脚下一滑，人和碗一起下来。

碗没碎。碗好好的，他躺在地上，半天没起来。

那天他给女儿打了电话，说不回来了。女儿在电话那头没问为什么，只说：你不是最爱那个碗吗。

是啊。他最爱那个碗。他连它为什么留着都想不明白。外祖母那会儿家里穷，一个碗传给三个人，最后传到他母亲手上，母亲脾气那么急一个人，碗在她手里传了两代，愣是没摔。

他想，等退休了他就回来住。想到今天已经二十四年。

现在他回来了，站在门口，梧桐的水泥补丁就在头顶上。他掏出手机，第三次拍了那棵树——前两次照片都被他删了，太难看。他看着相册里那张糊着水泥的树，凑近看，看了很久，然后关掉。

他走到巷口那家面馆，还没到饭点，老板在擦桌子。他问了一句：还做二两干拌么。

老板说：做。你是以前住这楼上的吧。

他说：是。

面端上来，葱花放多了。他吃了两口，抬头问：当年那个味道怎么找不到了。

老板说：没找。是您记错了。

他没争。低头把面吃完，碗底剩了一点汤。
