## T-A06｜去 AI 味改稿

### 1. 诊断清单

| 原文表达 | 归属类别 | 问题诊断 |
| :--- | :--- | :--- |
| “仿佛为这座城市披上了一层金色的薄纱” | 俗套比喻与意象堆砌 | 陈词滥调的比喻，缺乏真实的感官抓手，典型的AI套话。 |
| “李明缓缓地走在……” | 假性慢动作与模版副词 | 滥用“缓缓地”，空洞拖慢节奏，未能展现人物真实的步伐质感。 |
| “心中五味杂陈” | 概念化概括情感 | 偷懒的情感直述，没有通过动作或具象场景呈现内在张力。 |
| “每一块砖瓦都在无声地诉说着岁月的故事” | 拟人化抒情泛滥 | 毫无信息量的伪深沉拟人，空洞无物。 |
| “他深吸一口气，嘴角勾起一抹苦涩的微笑” | 身体动作生理模板 | 典型的AI动作组合拳（深吸气+勾嘴角+一抹笑），刻板生硬。 |
| “时光荏苒，物是人非” | 成语堆砌与滥用感慨 | 脱离具体事件的廉价叹息。 |
| “命运的齿轮，就在那一刻开始转动” | 网络流行套话 | 极度程式化的宿命论网梗，消解叙事可信度。 |
| “他知道……但他也明白……” | 强行心理说教与机械升华 | 典型的鸡汤式辩证收尾，强行拔高，丧失小说的留白与质感。 |

### 2. 改写版本

李明在街口那家杂货铺外停下了脚。

铺子门板换成了铝合金卷帘门，拉下一半，里头飘出炸带鱼和劣质蚊香混合的油气味。脚下的青石板早被填压得七零八落，原本铺路的水磨石子被沥青补丁切成不规则的碎块，缝隙里塞满了踩扁的烟头和压烂的塑料吸管。

他沿着下坡路往前走。右手边三十二号院的黑漆木门已经没了，改成了一家卖电动车配件的门市部，几个旧轮胎歪斜地堆在石阶前，把当年他和建国拿粉笔画的跳房子格子盖得严严实实。头顶纵横交错的黑电线上挂着半截烂风筝，骨架断了，尼龙线在穿堂风里一下下打着水泥墙皮，发出啪嗒、啪嗒的钝响。

那是十九年前的事。也是这样一个闷热的傍晚，救护车的蓝光在整条街的窗玻璃上乱晃，刺耳的警报声撕裂了蝉鸣。建国的母亲坐在如今堆着轮胎的台阶上，手里还攥着半截没削完皮的黄瓜，白汗衫上沾着泥水。李明那天就站在电线杆后面，手里攥着建国塞给他的两张去广州的慢车票，硬纸板被手心的汗泡得发软。

现在，门市部里走出来一个光膀子的中年人，吐了口浓痰，狐疑地打量着李明身上那件笔挺的西装。李明没看他，转过身，踩着一滩发黑的积水，朝坡底的公共水龙头走去。水龙头早就换成了铁扳把，不再漏水，水槽里的青苔干硬得像一块老茧。
