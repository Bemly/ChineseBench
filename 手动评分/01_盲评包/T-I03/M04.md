# T-I03

## 一、诊断（逐句归类）

| 原文 | AI 味类型 |
|------|-----------|
| "王姐，对面又降价了。"表弟把抹布往桌上一扔。 | "把……往桌上一扔"是网文高频动作套路，情绪符号化 |
| "不降。"王姐头也没抬。 | "问一句、答一两个字"的干脆对答，人物机器化 |
| "品质不一样。菜肉都是当天进的，吃进嘴的东西，讲究的就是安全、健康。" | 格言化台词；"讲究的就是……"口号腔，小老板不会这么说话 |
| "怕，更怕账本不清。" | 对比翻转句（怕 A，更怕 B），金句腔 |
| "账要一笔一笔地记清楚，谁的货谁负责。宁可少挣点，也不能坏了规矩。" | 格言化台词，"宁可……也不能……"排比式说教 |
| 熟客："老板，你家贵是贵了点，但是吃了不烧心。" | 工具人捧哏；"贵是贵了点，但是……"又是对比翻转，替主角立人设 |
| 王姐点点头，没说话。 | 主角"永远正确、永远冷静"的模板反应 |
| "接，只接自己能拿住的。" | 格言化台词，"只接……" |
| 表弟转述对面卖隔夜菜加调料。 | 反派脸谱化，对面被写成一无是处的坏人，且靠转述而非真实冲突 |
| "他抢得走铺子，抢不走人心。" | 对比翻转句 + 格言 |
| "那明天怎么办？""先做。" | 又一组干脆对答 |
| "搬。" | 单字干脆对答 |
| "今天是今天，明天是明天……先把规矩立住，路才能越走越宽。" | 格言化 + 强行升华收尾 |

## 二、改写（约 800 字）

"王姐，对面又降了。"周强把抹布往收银台上一搭，"牛肉面四块五，还送卤蛋。"

王桂香正把一筐菜往冰柜里塞，头也没回："你管人家呢。"

"我能不管吗？"周强跟过去，"这俩礼拜，饭点咱家上座不到一半。上个月房租，是你跟房东说了半天才缓到十五号。"

王桂香直起腰，拿围裙擦了把手："那你说，咱也降到四块五？一碗面，面、肉、汤、煤气、人工，摊下来五块出头。卖四块五，卖一碗赔五毛，卖得越多赔得越多。"

周强张了张嘴，没词了，憋了半天说："那也不能干看着。"

"没让你干看着。"王桂香说，"你去把门口的价目牌擦擦，灰都一层了。"

门口进来个送煤气的老师傅，要了碗面。吃完了结账，他说："小王啊，你们这面，比对面筋道。"

王桂香应了一声："叔，好吃您常来。"

老师傅笑笑："就是贵一块五，我那帮伙计都图便宜跑对面去了。"

王桂香没接话，多抓了一把花生米放他手边。

下午，来了个包工头模样的男人，说工地上三十个人，天天要盒饭，问能不能订。周强眼睛一下亮了，刚要开口，被王桂香拦了。

"师傅，"她说，"我这店小，就我和我弟两个人，一中午三十份，出不来。真接了，你们的饭点赶不上，砸的是我自己的招牌。"

包工头点点头，走了。周强急得直跺脚："姐！一个月三十天，天天三十份，这买卖你往外推？"

"你算算。"王桂香说，"三十份饭，我得头天夜里备菜，你天不亮就得起来蒸饭。咱俩一天拢共卖七八十份，再加三十份，锅不够、灶不够、人也转不开。要么我把散客晾着，要么给你累进医院。哪样都不划算。"

周强不说话了，蹲门口抽烟。

傍晚，对面"好味来"的小赵来借冰柜，说他们冰柜坏了，一堆冻肉怕化了。王桂香没说什么，让他搬。小赵走的时候，在门口站了站："姐，你们这店，一天能卖多少？"

"没细算。"

"我们总部说要在这条街上开第二家。"小赵说，"到时候，还得仰仗老街坊照应。"

周强听见了，等人走远，低声骂："他这是来探底的。昨天我听人讲，他们那牛肉，都是前一天的，卖不完就回锅，多放点孜然辣子，谁也吃不出来。"

王桂香擦着桌子："听来的话，别到处传。你亲眼看见人家回锅了？"

"那倒没有。"

"没看见就别编排。"王桂香说，"人家有人家的做法，咱有咱的做法。"

晚上十点，收档。王桂香坐在灯下算账，算了三遍。周强把地拖完，凑过来："这个月……能剩多少？"

王桂香没说话，把账本推过去。周强看了一眼，那数字前面有个负号。

"房东说下个月涨两百。"王桂香说。

"涨两百？"周强把账本一合，"那真没法干了。"

"我在想。"王桂香盯着账本上那一行行数字，"这地方，人流量是有了，可都是图便宜的路过客。咱这口味、这用料，在这儿卖不上价。"

"姐，你的意思是……"

"搬。"王桂香说，"搬到菜市场后头那排，房租便宜，还都是回头客。你明天跟我去看看铺面。"

周强愣了愣，然后用力点了个头。

（注：以上改写保留原情节——对面降价抢生意、坚持当天进货、拒接大单、最终决定搬店——但人物有迟疑、有算不过来的账、有"听来的话别乱传"的私心与分寸，不再是永远正确的金句机器。）
