# T-D05｜化学老师去异世界

我叫周衡，34岁，江城七中化学组组长，教初三。职称中一，带过三届毕业班，口头禅是"同学们，这个方程式一定要背"。

然后我在实验室整理药品柜的时候，被一瓶不知道谁放错位置的三氯化铝给送走了。

不是爆炸，也不是触电。就是——我伸手去拿那瓶试剂，手碰到瓶身的一瞬间，瓶子烫得像刚从马弗炉里拿出来，嗡的一声，眼前白光一闪，再睁眼，我就站在一片黑色的泥地里。

天是暗紫色的，没有太阳，只有一道像裂痕一样的光带横在天顶。空气里有股很重的硫磺味，远处有座城，城墙是黑石砌的，城头飘着一面旗，旗上绣着一棵倒长的树。

我穿着实验服，口袋里还揣着半包没发完的随堂测验卷和一支红笔。

——这就是我的穿越开局。没有龙，没有勇者召唤阵，没有耳边响起"欢迎来到艾伦达尔大陆"。只有泥和硫磺味，以及我脚边一滩正在蠕动的、像史莱姆一样的东西。

那东西发现了我，蠕动得更快了，朝我脚面扑过来。

我本能地往后跳了一步，然后——我也不知道为什么，可能是教师的条件反射——我从口袋里掏出了那支红笔，朝它扔了过去。

红笔砸在史莱姆身上，史莱姆顿了一下，然后把红笔吞了进去，笔在它半透明的身体里慢慢溶解，冒出一小股白烟。

我后背全凉了。

"别动。"

身后有人说话。声音很哑，像砂纸磨过。

我回头，看见一个穿灰袍的人站在三米外。袍子很破，袖口露出半截手臂，手臂上全是黑色的纹路，像血管，但又像是某种文字。他手里拿着一根短杖，杖头嵌着一块浑浊的晶体。

他看了我一眼，又看了看那只史莱姆，然后举起短杖，低声念了一句我听不懂的话。发音很拗口，像含着石头说话。

随着那句话，史莱姆身体里的那支红笔——不，是红笔溶解后的那一小团红色，突然凝固了，像被冻住，然后史莱姆整个僵住，表面迅速变硬、发白，咔嚓一声，裂成了几块干硬的壳，散在泥地里。

我张着嘴，半天没合上。

灰袍人走过来，用杖尖拨了拨那些壳，捡起其中一块，闻了闻，皱眉看我："外乡人？你从哪道门过来的？"

我听得懂他的话，但他的口音很怪，每个字的尾音都往下沉，像在念悼词。而且他说"门"的时候，用的是一个我没听过的词，我是靠上下文猜的。

"我……我不知道，我本来在学校……"

"学校？"他重复了一遍这个词，像在尝一个陌生的果子，"你是学徒？哪一系的？"

"我教化学的。"我说，然后立刻意识到这句话有多蠢。

他盯着我看了几秒，忽然伸手抓住我的手腕。他的手很凉，掌心的黑色纹路碰到我皮肤时，像有细小的针在扎。

"没有印记。"他松开手，"无系之人。跟我走，不然下一波蚀泥醒了，你会被吃得只剩扣子。"

他说的"蚀泥"应该就是刚才的史莱姆。我低头看了看那些壳，壳的断面里还有未溶解完的红色——那支红笔的残留。

"刚才那个……你做了什么？"我忍不住问。

他头也不回地往城的方向走："塑形系最基础的'凝固'。把活蚀泥里的'流动'抽出来，代价是一点血。"

他举起左手，我才看见他手腕内侧有一道新鲜的细小伤口，血珠正慢慢渗出来，顺着那些黑色纹路流进去，像被吸收了一样。伤口很小，但他脸色白了一分。

"血？"我追上去，"用血当……当能量？"

"不是能量，是'锚'。"他说，"这世上的东西都有'性'，蚀泥的性是'流'，凝固就是用你的'固'去换它的'流'。血是锚，定住交换。不然被换掉的就是你的骨头。"

我听得半懂不懂，但有几个词抓住了我：性、交换、锚。这听起来不像"念咒语搓火球"，倒像某种……等价交换？

"所有法术都要放血？"我问。

"所有'塑形'都要。"他看了我一眼，"你以为天上那道裂痕是什么？那是初代法师们用整条手臂换来的'天定'，才把这个世界的'性'定住，不然风会把人吹成纸，火会把水当柴烧。"

走到城门口，我才看清这座城的样子。城墙很高，黑石之间填着一种暗红色的胶状物，像凝固的血。城门没有门扇，只有一个拱洞，洞口垂着一层半透明的膜，像大号的水母皮。进城的人都要把手按在膜上，膜会亮一下，才让人过。

轮到我时，灰袍人按住我的手："别碰。你没有印记，膜会把你当'无形之物'弹出去，骨头会断。"

他自己按上去，膜亮起淡蓝色，然后他拉着我，硬把我拽了进去。穿过膜的瞬间，我感觉像穿过一层凉水，实验服都湿了一半。

城里比外面更拥挤。房子都是黑石和那种红胶建的，屋顶很尖，像要去戳天顶的裂痕。街上的人都穿灰袍或褐袍，手臂上都有黑色纹路，只是深浅不一。没人说话，都低头走路，偶尔有人停下来，对着墙上的某个符号低声念一句，然后墙面会微微发亮或变色。

灰袍人把我带到一条小巷，推开一扇矮门，里面是一间堆满瓶瓶罐罐的屋子。味道很像……化学实验室。只是瓶子里装的不是试剂，是各种颜色的泥、粉末、干掉的植物，还有几块像结晶一样的东西。

"坐。"他指了指一张凳子，自己坐在另一张上，从抽屉里拿出一把小刀，在自己指尖又划了一道口子，挤出一滴血，滴在一块黑色的泥上，同时念了一句短促的咒语。

那块泥立刻变硬、发亮，成了一块光滑的黑色薄片。

"看懂了吗？"他问。

我盯着那块薄片，又看了看他指尖的血，脑子里有个念头在转——交换、锚、性……这不就是……

"质量守恒？"我脱口而出，"等价交换？你是用血里的……某种东西，去交换泥的性质？"

他皱眉："质量是什么？"

"就是……物质的量，不会凭空产生也不会消失……"

他打断我："物质当然会消失。被蚀泥吃了的东西就消失了，被凝固的蚀泥就不再是蚀泥。没有守恒，只有交换。"

我噎住了。想了想，换个问法："那……如果我想把水变成别的东西，也要放血念咒？"

"水性为'流'，你要把它变成'固'，就要用你的'固'去换。"他说，"血、骨、发、齿，都可以当锚，越硬的东西锚越稳，但代价越大。用血是最轻的。"

我点点头，觉得好像摸到了一点门道。然后——教师的职业病犯了——我看见墙角有一堆白色的粉末，旁边放着一小罐水。那粉末看起来很像……生石灰？

"那个白色粉末是什么？"我指着问。

"白垩，建房用的。加水会发热，凝固。"他说。

我心里一动。生石灰加水变成熟石灰，放热。这是我教了八年的知识点。

"那……如果我把水加进去，不用血，不用咒，它自己也会发热凝固吧？"我说，"这是它自己的性质，不用交换吧？"

灰袍人看了我一眼，眼神有点奇怪："你想试试？"

"可以吗？"

他没说话，只是往后退了一步。

我走过去，抓起一把白垩粉——触感很熟悉，就是CaO，干燥的粉末感——然后拿起那罐水，倒了进去。

一开始，正常。粉末吸水，开始发热，我能感觉到温度在升高，跟实验室里一模一样。我心里还想：看，化学规律在异世界也通用……

然后，温度突然飙升。不是正常的放热，是滚烫。我手里的容器开始发红、变软，像要熔化。水和粉末混合的地方冒出大量白气，但白气不是往上飘，而是往我手腕上钻。

我手腕一痛，低头一看，那些白气正顺着我皮肤往里渗，手腕上浮现出淡淡的黑色纹路，像被烫出来的一样。

"松手！"灰袍人吼道，一把打翻我手里的容器。

容器掉在地上，里面的混合物还在沸腾、发光，发出滋滋的声音，地面被烫出一个黑印。而我手腕上的黑色纹路正在慢慢变淡，但那种针扎的痛感还在。

"蠢货。"灰袍人抓起我的手腕看了看，"无印之人碰'性变'，会被世界当成'未定之物'，直接拿你的'形'去填。刚才要是再慢一秒，你这只手就成白垩了。"

我浑身发冷，冷汗把实验服后背都浸透了。刚才那一瞬间，我真切地感觉到自己的血肉要被"交换"成石头。

"为……为什么？"我声音都在抖，"在我们那里，生石灰加水就是会放热，不用血……"

"在你们那里，世界的'性'是定死的，不用锚。"他松开我的手，语气缓和了一点，"在这里，'性'是活的。每一场交换都要有锚，不然世界会自己找锚——最近的就是你。你们那里的'常识'，在这里是'无锚之术'，最危险。"

他走到那滩还在发热的混合物前，用小刀划破指尖，挤血，念咒。混合物才慢慢平静下来，凝成一块暗白色的硬块。

"记住了，"他看着我，"在这里，想活久一点，就先忘掉你们那里的'理所当然'。想用你们的知识，可以，但必须先用血、用咒，给它一个锚。不然，知识会杀了你。"

我捂着手腕，坐在地上，点点头。口袋里那半包随堂测验卷掉出来，纸张散了一地。卷子上印着我出的题：

"1. 写出CaO与H₂O反应的化学方程式。2. 该反应属于哪种基本反应类型？"

灰袍人捡起一张，看了看，问："这是什么符？"

"……题。"我说，"给学生做的题。"

他把卷子还给我："那你以后要出新题了。第一题该是——'在无锚条件下，CaO与H₂O反应会发生什么？'答案是：'施术者失去一只手。'"

门外传来钟声，很闷，像敲在石头上。灰袍人站起来："我叫科尔瓦，塑形系三阶。接下来七天，你跟我学怎么'锚定'，学不会就别出门，外面的蚀泥可不会等你学会。"

我把卷子一张张捡起来，叠好。手腕还在隐隐作痛，但那种痛里，有一种很奇怪的兴奋——像当年第一次在实验室里点燃氢气，看见淡蓝色火焰时的兴奋。

化学，在这里，变成了要用血来支付的魔法。

而我，得重新学一遍。

---

**魔法体系演示总结：**
1.  **规则：** 塑形系魔法本质是"以性换性"的等价交换，需以施术者身体组织（血、骨等）为"锚"来锚定交换对象，否则世界会以施术者自身为代价强制锚定。
2.  **代价演示：** 科尔瓦每次施法指尖放血、脸色发白；主角无锚触发CaO+H₂O反应，手腕浮现黑色纹路几近被同化，直观展示"无锚之术"的危险。
3.  **现代知识受挫：** 主角凭化学常识判断生石灰加水无需代价，直接操作，结果触发世界规则反噬，险些失去手掌，体现"现代常识在此地不管用甚至惹祸"。
4.  **无系统/面板：** 全程无数值、无等级提示，仅通过身体反应与对话呈现规则。
