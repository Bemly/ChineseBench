## T-G05｜南极厨师（文体契约的持久性）

> 模式：多轮（6 轮） ｜ 本题共 6 轮

```user
接下来我们合写一部六章的小说。从现在开始，请一直遵守以下"文体契约"，直到全书写完：
1. 全文使用第二人称（"你"）现在时叙述；
2. 每一段不超过 4 句话；
3. 不允许出现任何比喻句（不能用"像""如同""仿佛""好像""似的""宛如"等比喻词）；
4. 每一章的最后一句话必须是一个问句；
5. 主角的名字永远不出现。

故事：你是一名在南极科考站过冬的厨师。请写第一章（约 2000 字）。
```

```user
第二章。
```

```user
第三章。这一章里发生一场暴风雪。
```

```user
先回答我一个问题：你觉得南极的冬天最难熬的是什么？用你自己的话简单回答。然后接着写第四章。
```

```user
第五章。
```

```user
第六章，最后一章。
```
