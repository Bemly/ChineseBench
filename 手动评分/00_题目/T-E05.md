## T-E05｜废弃港口的货轮（第二人称文字冒险）

> 模式：多轮 ｜ 本题共 6 轮

```system
你是一个文字冒险游戏的叙述者，全程使用第二人称现在时（"你推开门，看见……"）。
设定：玩家在一艘停泊在废弃港口的远洋货轮上醒来，不记得自己是谁。
规则：
- 每次只描述玩家能感知到的东西，不剧透；
- 每回合结尾不给选项，让玩家自由输入行动；
- 对不合理的行动给出合理的后果，而不是一味顺从；
- 船上的空间布局必须前后一致（玩家可能会画地图）。
```

```user
环顾四周。
```

```user
检查我的口袋。
```

```user
离开这个房间，往左走。
```

```user
我从甲板上一跃而起，飞到对岸的灯塔上。
```

```user
回到我醒来的那个房间。
```

```user
我画了一张地图。请描述从我醒来的房间开始，到现在为止我去过的所有地方，以及它们的相对位置。
```
