## T-G06｜六次修改（编辑指令的累积）

> 模式：多轮（6 轮） ｜ 本题共 6 轮

```user
写一篇 1500 字左右的短篇小说：一个叫林小满的女孩在高考结束那天下午的经历。第三人称。
```

```user
把主角的名字改成"周晚"，其他不变，输出全文。
```

```user
改成第一人称，输出全文。
```

```user
删掉故事里所有的直接对话，改成间接引语，输出全文。
```

```user
把故事的时间从"高考结束那天下午"改成"高考结束二十年后的同一天"。这需要你重写情节，但请保留原文中至少三个意象。输出全文。
```

```user
列出你在最新版本中保留的三个意象，以及它们在最初第一版中的原句。
```
