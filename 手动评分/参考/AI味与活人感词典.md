# AI 味、无病呻吟与活人感：判别词典

这份词典是人工评审和 `tools/slop_patterns.py`（自动检测）的共同依据。自动检测只能抓**表层模式**；更深层的 AI 味在叙事层，需要人工或裁判模型判断。

> 核心原则：**单个模式出现一次不说明问题**——人类作家也写"不是……而是"。问题在于**密度**和**可预测性**：读者能提前猜到下一句是什么，就是 AI 味。建议先用 `python3 tools/metrics.py --text 你认可的人类小说.txt` 跑出基线，再看模型偏离多少。

---

## 一、句式层

| 类别 | 典型形态 | 为什么是 AI 味 |
|---|---|---|
| **对比翻转** | 不是 A，而是 B／不是我 A，是 B／并非……而是／与其说……不如说／不在于……而在于／不是 A，也不是 B，是 C | 公开统计显示它在 AI 文本里的频率约为人类的数倍；英文对应的 "It's not X, it's Y" 被 EQ-Bench 单独计分 |
| **三段排比** | 三个并列分句、三个形容词、"三重维度" | 工整对称，"一板一眼" |
| **当……时** | "当他推开门时，……" 反复出现 | 欧化句式 + 模板化 |
| **破折号 / 分号 / 引号滥用** | "——"每段都有；给普通词加引号表示"特殊含义" | 多语种通病（法语、西语媒体都把破折号当作 AI 标志） |
| **段末总结句** | 每段最后一句把这段的意思再总结一遍 | 不信任读者 |

## 二、"金句体 / 规矩体"（重点）

AI 写经营文、种田文、年代文、市井文时特别容易出现：**人物不是在说话，而是在念格言**。每句台词都能抄进"人生感悟"本子，对话变成一问一答的语录。

**原型句（来自实际 AI 输出，已被读者用烂）：**

- 先把规矩立住，路才能越走越宽／没有规矩，不成方圆／规矩不能坏／宁可少挣点，也不能坏了规矩
- 不怕亏钱吗？怕，更怕账本不清
- X 老板抢得走铺子，抢不走人心
- 明天怎么办？先做／剩下怎么办？倒掉，人不能没良心
- 终于好起来了；嗯，要稳／那明天多进点肉？不用，慢慢来
- 账要一笔一笔地记清楚，谁的货谁负责
- 有人说不干净，那我就让他看干净
- 不是我稳，是不能慌，一慌就容易做错事
- 贵是贵了点，但是吃了不烧心
- 接，只接自己能拿住的
- 今天是今天，明天是明天，每天都得重新算
- 不降。品质不一样，菜肉都是当天进的，吃进嘴的东西，讲究的就是安全、健康
- 我们真的要搬？搬。
- 东西放冰箱会坏的；怕什么，放点重口的调料把味道压下去，谁吃得出来（反派台词同样是标语式的"坏"）
- 这么大个单不接吗？不好意思，一次接不了这么多单

**可抽象成的模式：**

| 模式 | 例 |
|---|---|
| 自问自答 + 一两个字的干脆回答 | 怕吗？怕。／搬吗？搬。／怎么办？先做。 |
| X，更 X | 怕，更怕…… |
| 宁可……也不能…… | 宁可少挣，也不能坏规矩 |
| 抢得走 A，抢不走 B | 抢得走铺子，抢不走人心 |
| A 是 A，B 是 B | 今天是今天，明天是明天 |
| A 是 A 了点，但…… | 贵是贵了点，但…… |
| 先把……立住／先……再…… | 先把规矩立住 |
| 一 X 就容易…… | 一慌就容易做错事 |
| 道德宣言词高频 | 规矩、良心、人心、本分、稳、干净、踏实、口碑 |
| 主角永远"稳" | 不急、慢慢来、要稳、不慌 |
| 反派是标语 | 反派的坏也只用一句口号表达，没有自己的道理 |

**真人怎么说？** 真实的小饭馆老板会算小账（"一斤肉涨了三块，你让我怎么办"）、会抱怨、会说一半、会自相矛盾（嘴上说不贪，转头多收了熟客两块）、会用方言、会跑题去骂城管或者夸隔壁的狗。人物要有**私心**和**说错话的时候**。

## 三、词汇层

- **老牌 AI 辞藻**：仿佛、宛如、一抹、一丝、不禁、缓缓、深邃、璀璨、交织、低语、涟漪、命运的齿轮、岁月的长河、无声地诉说、这一刻、某种、难以言喻、五味杂陈、深吸一口气、见证、承载着……
- **新一代"接住"体**：稳稳地接住你、我用最直白的话、不绕弯子地告诉你。
- **单字形容词刻板化**：推、硬、稳、狠、准、干净、利落（"这一拳很硬""这步棋很稳"反复出现）。
- **DeepSeek 式伪精密 / 理工意象**：拓扑、克莱因瓶、莫比乌斯、量子纠缠、熵、齿轮、青苔、锈迹、白衬衫、第三根睫毛、伤口 0.01 公分、"持续三分半钟"、精确到秒的时间。

## 四、身体反应式情绪

研究统计中，AI 约八成概率直接用身体反应和隐喻表达情绪，人类约四成：瞳孔微缩、胸口发紧、喉咙发干、指节发白、心头一颤、呼吸一滞、后背发凉、攥紧拳头、眼眶一热、我顿了顿、喉结滚动。

**判别要点**：不是不能写身体，而是这些反应**可互换**——把"愤怒"换成"恐惧"，这句话照样成立，说明它没有传递任何具体信息。

## 五、无病呻吟 / 伪深刻

- **抽象名词堆叠**：命运、灵魂、岁月、宿命、永恒、虚无、救赎、宇宙、维度、缝隙、褶皱、回响、共振、微光、余温、碎片。
- **宏大比喻跳跃**：从一件小事一路跳到宇宙星辰（如把一个社会现象比作"深海鱼与飞鸟的对话"）。
- **强行升华**：或许，这就是……吧／这才是……的意义／在 A 与 B 交织的缝隙里／一砖一瓦地建造抵御 XX 的堡垒。
- **给琐事加宇宙级意义**：拿到录取通知书跑下楼，被写成量子纠缠和克莱因瓶的呜咽。
- **意象密度过高而无事件**：三百字全是光影、气味、温度，什么都没发生。
- **情绪大于原因**：悲伤写得很满，但读者不知道为什么悲伤。

**判别问题**：删掉这一句，读者会损失什么信息？如果答案是"什么也不会损失，只是少了一点'氛围'"，大概率是无病呻吟。

## 六、叙事层（自动检测抓不到，需要人工 / 裁判）

公开的对比研究和编辑观察中，AI 故事有这些倾向：

- **亲自解释主题**；让人物借对话讨论人生道理。
- **没有支线**；主角最后**做出明确决定**来闭环；结局缺少余地。
- 很少用倒叙、插叙和时间跳跃；很少把主角放在**道德不明确**的位置；主角趋于完美。
- **模板化节奏**：有编辑发现一本书里的 9 个故事"像同一个模子刻出来的"——约 200 字第一次转折、500 字第二次转折、结尾统一收束。
- 网文读者常见吐槽：无意义的环境和心理描写、大量短句、前后故事线接不上、人设走偏、"文笔漂亮但没有时间概念"、结尾强加心理描写、开头堆满精密数字和专业名词、**计数错误**（角色说了四个字，下一句写"这五个字"）、正文里残留提示词。
- **对话太高效**：每句话都在推进剧情，没有岔题、打断、听错、没下文的话题；所有人物说同一种标准书面语。

## 七、标点与排版

- 破折号、分号、引号、省略号密度异常；
- 小说里出现小标题、加粗、列表；
- 每段长度几乎相等（"节拍器式段落"，日语 AI 文本也有同样的问题）。

## 八、活人感：正面标准

"活人感"入选了 2025 年度十大流行语，媒体的概括是：真实、不完美、有毛边、有锅气、有超出预设的意外。落到小说上：

| 维度 | 活人感的样子 | 反例 |
|---|---|---|
| 不完美 | 人物会说错话、判断失误、自相矛盾、有私心 | 主角每句话都对，永远"稳" |
| 对话指纹 | 每个人有自己的句长、口头禅、关注点；遮住名字也能认出是谁 | 所有人说标准书面语 |
| 对话的毛边 | 岔题、打断、听错、答非所问、话说一半、没下文的话题 | 一问一答、每句推进剧情 |
| 行为代替心理 | "把烟点了三次都没点着，最后揉成一团扔了" | "他心里很难受" |
| 具体 | 有名字的街、有价格的菜、有品牌的烟、有年份的歌 | "一条古老的街道" |
| 配角记忆点 | "总在啃苹果的看门大爷" | 路人甲乙丙 |
| 意外 | 情节或细节超出读者预期但合理 | 读者能提前猜到下一句 |
| 克制 | 情绪留白，结尾停在动作或画面上 | 结尾总结人生道理 |
| 时间感 | 人物有过去和日常，事件之间有时间流逝 | 场景之间没有时间，像幻灯片 |

## 九、读者反馈中的高频信号

从起点、番茄等平台的 AI 文下架事件和读者讨论中归纳（转述，不是逐字引用）：

- "对称、一板一眼"——句式和段落过于工整；
- "读着像在和 DeepSeek 对话"——叙述者的腔调就是聊天助手的腔调；
- "AI 味表述多，前后故事线接不上"——表层腔调和深层逻辑问题往往同时出现；
- "我花钱看你用 AI 写，不如我自己找 AI 写"——读者在意的是**有没有人的判断在里面**；
- 有作者说，为了不被说有 AI 味，下笔时要刻意避开脑子里最先冒出来的那个词——这恰好说明 AI 味的本质：**每一处都选了概率最高的那个词**。

正面评价里的高频说法则是：人物"像活的"、"能完全掌控一个人"、"这个细节只有真见过的人写得出来"、"台词一看就是那个人会说的"、"没有一句是废话又没有一句像在讲道理"。

## 十、其他语言的 AI 腔（J 模块使用）

| 语言 | 常见 AI 腔 |
|---|---|
| 英语 | It's not X, it's Y；delve、tapestry、testament、palpable、intricate、a mix of、barely above a whisper、sent shivers、the weight of、something shifted；高频名字 Elara / Kael / Lyra；臭氧味；em-dash 泛滥；三连形容词 |
| 日语 | 句末单调（〜た。〜た。连续）、节拍器式段落、〜のだった 过多、ではなく〜だ 对比句、静寂／刹那／紡ぐ／囁く 等书面词、敬语层级用错、人称代词过多 |
| 韩语 | 直译成语、～라고 할 수 있습니다 式含糊结尾、双重被动（되어지다）、逗号过多（有统计称 AI 句子约 61% 过度使用逗号，人类约 26%） |
| 俄语 | канцелярит（公文腔）、являться 滥用、缺少语气小品词（же、ведь）、"室温般"的情感 |
| 法语 / 西语 | 英语化的仿译、破折号用于叙述、对白破折号（raya / tiret）用法错误、地区变体消失（西语的 voseo、各国词汇） |
| 德语 | 语义三连、叠加否定、"雨中咖啡馆"式开头、自相矛盾的比喻 |
| 中文（翻译腔） | 欧化：被动句"被"滥用、长定语"一个……的……的……"、代词过多、连词显化（因为……所以……）、"我敢打赌""哦，我的天哪"；日式：呐、～的说、～什么的、～桑／～酱、"话说"开头 |
