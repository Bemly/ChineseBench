# 手动评分（评分工作区分发包，可整包复制）

> 本目录由脚本机械切割生成，**未改写任何原文一字**。原题库与答题卡均原位保留。
> 本目录**不含解盲信息**，可整包复制给评分工作区；解盲密钥只在
> `手动解盲（主会话专用）/`，绝不分发。

## 结构

```
手动评分/
  00_评分指令.md      LLM 裁判读此文件执行（任务、读写范围、步骤、输出格式、防作弊条款）
  00_题目/            每小题一文件（T-A01.md … T-J16.md，共 107），字节原样切自 手动题库/*.md
  01_盲评包/<题号>/   每题一目录，内为 M01.md … Mxx.md（匿名，x = 该题实际作答模型数）
  02_记分表/<题号>.csv  每题一空表（十维 + 通用均分 + 专项 + 总分 + 一句话点评，与参考/通用评分量表.md 对齐）
  04_汇总/            空，主会话解盲后写总表
  参考/               评分/ 下 3 个文件的逐字节拷贝（通用评分量表、AI味词典、多语言规则
  参考/评分要点/      每小题一文件（T-A01.md … T-J16.md，共 107：题头 + 考察行 + check 配置 + 评分要点节），
                      机械切自 题库/*.md（原版题库；手动题库的题干与之一致，唯一差异 T-G04 见下）
  参考/素材/阿Q正传.txt  仅 T-G04 需要（核对“针”句与引用是否属实），拷自 手动题库/素材/
  _tools/split.py     切割脚本（可重跑审计）
```

## 切割方式（防作弊声明）

- 单题文件（文件名即 `T-XXX.md`，如 deepseek / Muse 1.2）：**整文件字节原样拷贝**。
- 合卷（`## T-XXX` / `### T-XXX` 开头，如 LongCat / Qwen / gemini / claude）：从题头行行首切到下一题头行首，**原字节原样写入**，不增删一字、不改标点换行。
- 无题头的续写 part（如 space-bunny G/J 按“覆盖题目”分 part）：整文件按题归位，同（模型，题）多文件按 part 编号**纯拼接（零分隔符）**。
- 跳过（有记录，不删除）：`Muse Spark 1.2 Contributor/README.md`（索引非作答）、`space-bunny/check_g05.py`（检查器非作答）。
- 匿名：每题独立随机打乱（seed 每轮更换、仅主会话记录），M 编号**每题重新洗牌**，不可跨题追踪；换 seed 重切后历史 Mx 对应关系即作废。
- 盲评包文件内容**零包装头**：文件名即题号+匿名ID，内容即答题卡原字节。
